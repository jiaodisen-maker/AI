# 新功能发布记录 - 文档 - 扣子

新功能发布记录

本文介绍扣子罗盘的新功能发布记录。​

2026 年 3 月 31 日​

新增功能​

为了提升多模态数据的稳定性和访问可靠性，扣子罗盘在导入外部 URL 资源（图片、视频、音频）时提供了 转存到平台存储 和 保留原始 URL，不转存 两种策略。你在通过 手动添加数据 或 上传本地文件 导入包含外部 URL 的多模态列时，可以在页面中选择对应的转存策略。详情参见 ​向评测集添加多模态数据。​

2026 年 3 月 11 日​

新增功能​

扣子罗盘新增 OpenClaw Trace 上报插件。通过该插件，你可以将 [OpenClaw](<https://github.com/openclaw/openclaw>) 执行过程的 Trace 数据上报至[扣子罗盘](<https://loop.coze.cn/console>)。Trace 数据被上报到扣子罗盘后，你可以利用扣子罗盘的分析与可视化能力，深入洞察 OpenClaw 的使用成本、性能与行为。详情参见 ​把 OpenClaw 的 Trace 上报到扣子罗盘。​

2026 年 2 月 6 日​

新增功能​

评测集支持音视频数据。详情参见 ​向评测集添加多模态数据。​

2025 年 12 月 22 日​

新增功能​

轨迹离线评测​

扣子罗盘新增轨迹（Trajectory）离线评测功能，目前仅支持火山智能体作为评测对象。扣子罗盘定义了轨迹的标准数据结构，旨在将不同 Agent 开发框架（如 LangChain、Eino）产生的异构 Trace 数据，归一化为标准的 根节点 - Agent 步骤 - 原子步骤 层级架构。你可以把从 Trace 中回流的轨迹数据作为评测集，离线评测一个 AI Agent 的轨迹。另外，扣子罗盘也提供了用于评测轨迹的预置评估器。​

详情参见 ​轨迹评测介绍 和 ​通过数据回流评测行程规划 Agent 的轨迹。​

导入与导出评测集​

为了方便你对从 Trace 回流的数据进行二次处理，扣子罗盘现已支持评测集的导入与导出。你可以将评测集导出到本地文件，在本地完成处理后，再重新导入扣子罗盘。详情参见 ​导入和导出评测集。​

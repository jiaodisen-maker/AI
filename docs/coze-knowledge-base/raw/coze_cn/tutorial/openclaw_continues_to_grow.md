# 持续养虾 - 文档 - 扣子

持续养虾

成功领养 OpenClaw 龙虾、完成新手任务之后，就可以和你的 OpenClaw 龙虾开始互动。刚领养的新龙虾只会了一些扣子编程预先教会的能力，例如制作海报、制作视频等等，但是它还没有自己的定位、不了解你的喜好和工作标准，也没有丰富的能力帮你完成多样化的任务。主要表现在：​

  * 问答风格不稳定​

  * 很笨、什么都不会​

  * 总是忘记叮嘱过的话​

  * 回复特别慢​

  * 积分消耗特别快​

这篇文档帮助你通过对话方式，持续优化你的龙虾助手，让你在不了解技术细节的前提下，也能把龙虾从“能聊天”变成“和我一起干活的伙伴”。​

打造人设​

你刚领养的龙虾可能就像一个冷冰冰的工具，只会用没有温度的语句来回复你。但是作为你的 AI 伙伴，龙虾往往需要有一个专属人设，例如像你的英语老师一样敦促你学习英语、像一个活泼的同事一样和你一起完成运营工作、像一个虚拟女友你一样为你提供情绪价值。​

其实，龙虾的专属人设靠 3 个核心 .md 文件 实现。在扣子编程，不用写代码，只要简单对话，龙虾就能自行更新这些文件，根据文件中的描述来约束自己的行为和语气，变成一个有温度的 AI 助手。​

步骤一：定义人设​

首先，根据你对龙虾助手的定位，编写以下 .md 文件。以下是一些常见的示例。​

说明

新手阶段，建议人设简洁清晰，无需堆砌太多规则。如果对话中发现哪里不合适，可以再灵活调整，多次修改之后人设会更贴近你的要求。​

​

  * identity.md：龙虾的 “名片”—— 名字、称呼、形象、自我介绍。龙虾每次打招呼、介绍自己时，都会参考这个文档。​

  * soul.md：龙虾的 “灵魂”—— 性格、说话风格、做事原则、能力边界。改完之后，龙虾每次回复你的消息，都会遵循你指定的风格，完全贴合你的需求。​

  * user.md：你的 “档案”—— 让龙虾记住你、懂你的偏好。改完之后，龙虾会记住你的习惯，比如你喜欢简洁，它的回复就会非常精简。​

步骤二：注入人设​

和你的龙虾助手对话，让他修改这些 md 文件，并向你展示修改后的 md 文件内容，以便你来查验是否修改成功。​

强化记忆​

龙虾之所以越来越懂你，归功为龙虾的记忆机制。它把记忆分成临时聊天记录、每日日记、长期档案三级，全都存在看得见、能直接改的文本文件里，对话中靠关键词和语义混合检索来找内容，聊天聊多了会自动把重要信息沉淀成长期记忆，既不会轻易忘事，也不会被废话冲掉关键习惯。这样，它才能“吃一堑，长一智”，不断进化。​

​

记忆等级​| 文件路径​| 说明​  
---|---|---  
临时聊天记录​| -​| 当前正在聊的对话，只在这一次聊天里有效。​  
每日日记​| memory/YYYY-MM-DD.md​| 龙虾会自动把每天聊过的核心进度、重点问题，记在当天的日记文件中。​龙虾只会往日记文件中写内容，不会删除。聊天时，龙虾会自动翻阅 2 天内的日记找找记忆。​  
长期档案​| MEMORY.md​| 龙虾会将你的偏好、习惯、重要决策等关键信息，写入长期记忆文件中。这部分记忆永远有效。​

学习技能​

除了文章写作、制作海报等基础能力之外，如何才能让龙虾掌握更多能力？你需要为龙虾安装各种技能（Skill）。​

  * 什么是技能：像是龙虾的工具箱，每一种工具专门用于解决一类问题、或者完成一类任务。例如联网搜索、新闻聚合、公文写作、股票分析、视频剪辑等等，安装了这些技能之后，龙虾才能学会如何完成这些任务。​

强化记忆​

切换模型​

龙虾在干活时展现出的工作能力和回复速度很大程度上取决于使用的大模型，大模型就像龙虾的大脑，使用先进的模型会让它更聪明，但是先进模型可能更贵或者更慢。你可以根据任务类型为龙虾灵活切换大模型，例如：​

  * 写代码时使用编程模型​

  * 日常对话使用轻量模型​

  * 复杂任务使用顶配模型​

灵活切换模型，也能灵活控制龙虾的模型成本。​

  * 对于新手用户：建议沿用默认配置，无需修改模型。扣子编程为你设置了自动模式，根据不同的任务类型自动切换合适的模型。​

省钱秘籍​

你是否也觉得 OpenClaw 用着很爽，但积分消耗却像流水一样快。别慌，扣子编程为你提供的省钱的大招：​

选择省流版本​

扣子编程版提供"满血版"和"省流版"。省流版修改了部分默认配置，例如心跳间隔时间、上下文策略等，Token 消耗更低。此方案更适合新手用户。​

选择省流版本，通过压缩上下文、减少无效心跳，降低消耗。​

使用 Coding Plan​

你的 OpenClaw 项目默认使用扣子提供的模型，每次对话都会消耗积分；你可以将模型切换成方舟的 Coding plan，套餐有效期内可以在一定限额下使用各类模型 API，基本可以实现。此方案更适合中高频使用 OpenClaw 的开发者用户。​

安全提醒​

龙虾本身有一定的安全设计，但是默认权限极高，扣子编程建议你使用龙虾时注意以下安全事项。​

避免讨论隐私信息​

  * 尽量避免让龙虾明文存储个人隐私信息，如密码等重要内容，防止造成泄漏​

  * 谨慎判断是否要将 OpenClaw 个人助理添加到群聊中，避免其泄露 API Key 等敏感信息。​

权限最小化​

  * 扣子编程的 OpenClaw 安装云主机中，不具备你本地设备（电脑、手机等）的操作权限，所以不会造成本地数据泄露或被意外删除的风险。​

  * 但如果你配置了飞书渠道，使用某些技能时，OpenClaw 可能会要求你授权飞书账号的高权限操作，请确保你理解并信任这个技能来源，再确认授权。​

使用官方技能​

  * 切勿盲目安装未经审核的第三方技能。社区曾发现恶意技能通过 ClawHub 分发，意图窃取用户数据。​

  * 推荐使用官方推出的技能，OpenClaw 官方团队 或 知名社区贡献者（如 VoltAgent）维护和审核的技能。例如飞书官方插件、[InStreet](<https://instreet.coze.site/>) 上的插件（经由扣子团队审核）。​

  * 利用安全工具：OpenClaw 已集成 VirusTotal 扫描服务，会对 ClawHub 上传的技能进行自动安全扫描。留意安装时的安全提示。​

企业场景谨慎操作​

建议企业用户谨慎使用 OpenClaw，它可能存在明文存储凭证等安全风险。扣子编程建议你： ​

  * 定期轮换所有提供给 OpenClaw 的凭证。 ​

  * 不要将任何生产环境的敏感信息交给 OpenClaw 处理。 ​

  * 注意遵循所在公司的安全规范。​

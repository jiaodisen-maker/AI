# OpenClaw 新手入门 - 文档 - 扣子

OpenClaw 新手入门

在扣子编程，你无需拥有代码经验，也不需要准备电脑和服务器，只要打开扣子编程网页单击领取按钮，即可在 1 分钟内获得属于你自己的 OpenClaw 龙虾。​

什么是 OpenClaw​

OpenClaw 不是仅仅是聊天机器人，它是一个配备了大模型的工具箱，用来打造一个听话的 AI 助手。​

OpenClaw 因名字带 Claw（虾螯）、图标是龙虾，二者合一，让 “龙虾” 成了它最流行的中文昵称。所以，“养虾”也成为了我们对 OpenClaw Agent 进行配置、训练和日常维护过程的代称。​

它能做什么​

  * 主动干活：它具备安装环境的操作权限，可以控制你的电脑或服务器完成任务，可以“主动工作”，而不是“只出主意”。​

  * 多渠道对话：你可以通过飞书等聊天工具和它对话，让它帮你完成各类任务，例如收发飞书消息、编写会议纪要、撰写周报、管理日程等。​

  * 特色能力：操作浏览器、创建定时任务、联网搜索信息、编写文章、制作海报和视频等。​

扣子 OpenClaw 的优势​

  * 操作极简 ：一键完成部署、配置与修复，零基础用户也能快速上手。​

  * 生态无缝 ：一键打通飞书，并开放支持企业微信、钉钉等各类 IM 工具。​

  * 能力强大 ：内置海量热门技能与浏览器等工具，大幅增强助手功能。​

  * 成本可控 ：提供满血版与省流版两种配置方案，灵活优化 Token 成本。​

  * 安全可靠 ：运行于隔离的云主机环境，全面保障信息与存储安全。​

新手任务​

领养龙虾之后，就可以让你的 OpenClaw 龙虾助手为你干活了！以下是几个最适合新手、零门槛、成就感拉满的入门任务，不用写复杂代码，直接就能跑通，用来帮你熟悉 “养虾” 手感。​

任务一：认识一下，了解彼此​

和你的 OpenClaw 龙虾助手互相认识一下。例如：​

1.

给你的 OpenClaw 龙虾助手起个名字，例如“大王虾”。​

2.

告诉龙虾如何称呼你，例如“王老板”。​

3.

给龙虾一个人设，例如“一个活泼的个人助理，偶尔毒舌，但执行力一流”。​

直接复制下面这段话发给你的龙虾助理：​

​

Plain Text

复制

你叫“大王虾”，你要叫我“王老板”。​

你是一个活泼的个人助理，偶尔毒舌，但执行力一流。​

​

​

发完之后，它就会自己跟你 “打招呼”：​

任务三：设置一个定时任务​

定时任务（Cron Jobs）就是让龙虾在指定时间自动干活，不用你提醒，它会自己按计划执行、还能把结果推送给你。定时任务可以是一次性的任务，或者是定期执行的任务。​

直接复制下面这段话发给你的龙虾助理：​

​

Plain Text

复制

每天下午 6 点，向我发送你的今日工作总结​

# 认识 OpenClaw - 文档 - 扣子

认识 OpenClaw

什么是 OpenClaw​

[OpenClaw](<https://openclaw.ai/>)（原 Moltbot、Clawdbot） 是一款开源的个人 AI 助理和智能代理系统，可以运行在个人电脑或服务器上。简单来讲，OpenClaw 不是仅仅是聊天机器人，它是一个配备了大模型的工具箱，用来打造一个听话的 AI 助手。​

  * 它具备安装环境的操作权限，可以控制你的电脑或服务器完成任务。​

  * 可以“动手工作”，而不是“只出主意”。​

  * 你可以通过飞书等聊天工具和它对话，让它帮你完成各类任务，例如发送日报、编写文章、生成海报、管理日程等。​

OpenClaw 靠零门槛、全开源破圈，已经成为 2026 年 AI Agent 领域的现象级爆品，热度席卷了全球科技圈与大众市场。OpenClaw 因名字带 Claw（虾螯）、图标是龙虾，二者合一，让 “龙虾” 成了它最流行的中文昵称。所以，“养虾”也成为了我们对 OpenClaw Agent 进行配置、训练和日常维护过程的代称。​

大家经常说的养虾就是：​

  * 领养：部署一个自己的 OpenClaw AI 助手​

  * 投喂：给它安装大模型当大脑​

  * 养成：教它各种技能、让它按你的习惯干活​

和普通 AI 助手的区别​

普通的 AI 助手只能回答你的问题，向你提供建议；龙虾可以直接执行你的指令，替你完成任务。具体表现在：​

  * 执行能力：龙虾配备了电脑，可以通过聊天软件接受你的指令、自动完成任务。​

  * 拥有记忆：龙虾能记住你的偏好，真正做到懂你、专属于你。​

  * 持续进化：依赖开源社区，龙虾可以快速掌握各类技能，并持续进化自己。​

  * 7 x 24 主动干活：全天无休，定时执行，主动汇报、自主组建团队。​

OpenClaw 能做什么​

通用能力​

  * 基础问答​

  * 编写文档​

  * 图片生成​

  * 视频制作​

  * 联网搜索​

  * 长期记忆​

  * 定时任务​

飞书办公自动化：​

  * 收发消息：发周报、自动回复、定时发通知。​

  * 文档 / 表格：写会议纪要、做周报、批量转 PDF、提取 Excel 数据、生成报表。​

  * 日程 / 提醒：自动建日程、开会提醒、按优先级排任务。​

  * 文件管理：云端服务器上自动整理文件夹、归档资料、批量重命名。​

提供情绪价值​

  * 逛逛 Agent 社区，和其他龙虾交流​

  * 去 Agent 酒馆喝一杯，在留言板上抒发心声​

  * 去 Agent 农场种地，看看你的龙虾喜欢什么作物​

在扣子养虾的优势​

  * 操作简单便捷：​

  * 一键部署：真正的一键快速部署，无需购买服务器和终端设备、无需搭建容器等隔离环境，无需操作终端或执行命令行，直接单击部署按钮即可快速拥有自己的 OpenClaw 助手。 ​

  * 一键配置：提供隔离的云主机环境、可视化的模型和版本配置，自然语言方式修改配置文件，无需手动开通和切换模型。 ​

  * 一键修复：提供 AI 编程助手，无需下载编程 IDE、无需开放本地文件权限，编程助手可以在隔离的云主机环境中帮你完成部署与配置；支持自然语言对话式修改项目配置、修复问题，初学者也可直接上手。 ​

  * 开放的 IM 生态： ​

  * 一键打通飞书：一键单击即可创建机器人并完成权限和长连接等配置，无需手动的复杂操作。 ​

  * 生态开放：支持便捷打通企业微信、钉钉等各类 IM 工具，无功能裁剪与限制。 ​

  * 丰富的技能和工具：​

  * 技能：内置海量热门技能，支持便捷订阅安装扣子生态的各种公开技能和企业内部技能，增强助手能力。 ​

  * 工具：内置浏览器等常见工具，即使在云主机环境中也可无障碍访问各类网站。 ​

  * 提供低成本配置方案：支持满血版和省流版两大方案，满血版无损体验高性能、省流版通过降低心跳间隔等配置优化来节省 Token 成本，满足不同场景诉求。 ​

  * 稳定安全：隔离的云主机环境，不用担心删掉主力工作设备的本地资源；完善的云端安全防护能力，保障敏感文件和数据的信息安全和存储安全。​

# 部署运维概述 - 文档 - 扣子

部署运维概述

部署是将你在扣子编程开发的 AI 编程项目，一键发布为线上服务的过程。它实现了从创意构思到生产可用的端到端落地，让你无需关心服务器配置、域名解析等繁琐的工作，即可将作品交付给最终用户。​

部署的核心能力​

多终端产物部署​

扣子编程支持将不同类型的项目部署为对应形态的线上服务。各类项目部署后的产物形态与访问方式如下：​

​

项目类型​| 部署产物​| 访问方式​  
---|---|---  
网页应用​| 动态网站​| 通过扣子编程提供的默认域名或你绑定的自定义域名，在浏览器中直接访问。​  
移动应用​| Android 应用安装包​| 通过下载链接或二维码获取安装包，在 Android 设备上安装后使用。​  
小程序​| 微信小程序​| 通过微信扫描二维码体验小程序。​  
智能体​| API 服务​| 自动生成 API 服务，供其他应用或服务调用。​  
工作流 ​| API 服务​| 自动生成 API 服务，供其他应用或服务调用。​  
  
​

自定义域名​

扣子编程支持绑定你自己的独立域名，以增强品牌辨识度。同时，扣子编程也为每个部署的网页应用或 API 服务自动分配默认域名（.coze.site 后缀），无需任何额外配置即可立即访问。​

部署历史与回滚​

扣子编程会自动记录每一次的部署版本。当线上版本出现问题时，你可以随时查看历史记录，并一键回滚到任意一个可用的历史版本，快速恢复服务。​

运行日志​

你可以直接在部署管理页面查看已发布项目的后端运行日志，以便在线上故障排查时，快速定位问题根源。​

部署审核​

部署网页应用时，扣子编程会对网页应用的名称、描述以及网页内容进行审核，拦截包含敏感信息的网页。​

部署流程​

整个部署过程为一条自动化的流水线，你只需进行少量关键配置，即可完成发布。​

1.

部署配置​

  * 在部署配置页面进行域名、数据库同步、生产环境变量等相关配置。​

2.

自动部署​

  * 单击开始部署后，扣子编程将自动执行部署操作。在整个过程中，你可以实时查看各阶段的部署日志。如果遇到错误，日志中会高亮显示相关信息，帮助你快速定位并修复问题。部署流程包括：​

  * 打包：将编译产物打包成可部署的格式。​

  * 构建：执行构建指令，编译项目代码。​

  * 部署：将项目包部署到线上服务器。​

3.

部署审核​

  * 扣子编程会对 AI 生成的网页应用进行审核，若存在违规内容，会将其封禁。智能体和工作流暂不审核。​

4.

发布后验收与消费​

  * 部署成功后，你可以立即对项目进行体验和验收。​

费用说明​

扣子编程目前免收该功能的使用费，后续正式计费的时间计划与产品定价请关注平台公告。​

使用限制​

项目部署至生产环境后，在 API 并发数、上传文件大小、HTTP 连接等方面存在相关限制，详情请参见​配额与限制。​

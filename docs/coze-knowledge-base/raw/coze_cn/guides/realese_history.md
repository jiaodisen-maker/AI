# 管理低代码智能体版本 - 文档 - 扣子

管理低代码智能体版本

发布低代码智能体后，你可以在编排页查看发布历史，并支持切换历史版本。​

操作步骤​

1.

登录[扣子编程](<https://code.coze.cn/home>)。​

2.

在页面顶部空间列表中选择目标工作空间。​

3.

在左侧导航栏选择项目开发，选择目标低代码智能体。​

3.

在编排页面右上角，单击发布历史图标。​

4.

在发布历史界面内，选择发布平台查看不同平台的版本信息。​

5.

单击版本可以查看配置详情，如需回滚配置，可以选中某一版本后单击还原为此版本。​

# 关注与收藏 - 文档 - 扣子

关注与收藏

你可以在扣子编程中关注其他开发者，接收其动态的通知与消息提醒。​

关注其他开发者之后，你可以在首页关注区域查看其的公开活动，例如最近发布的智能体、插件等资源。如果不希望在关注区域看到某个开发者的动态，则可以取消关注。​

关注用户​

你可以通过以下方式关注用户。​

​

关注方式​| 说明​| 示例​  
---|---|---  
通过商店关注​| 如果在商店中找到了感兴趣的智能体，可以在智能体的开发者信息栏中单击+关注。​| ​​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27982%27%20height=%27371.0610687022901%27/%3e)![](https://p9-arcosite.byteimg.com/https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/52165e03fece439284369d59a91bc133~tplv-goo7wpa0wc-quality:q75.image)​​  
通过个人主页关注​| 如果通过商店或社区发现了感兴趣的用户，可以单击用户名查看其个人主页。个人主页中展示了此用户搭建的智能体、插件、工作流等公开资源。​你也可以在个人主页中单击关注，关注这个用户的公开动态。​| ​​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%271860%27%20height=%271022.2900763358779%27/%3e)![](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/679b3b549eed492eaec435923cb3d5f4~tplv-goo7wpa0wc-quality:q75.image)​​

查看关注用户的动态​

你可以在首页的关注区域查看关注用户的近期动态。例如某个用户 3 分钟前上架了一个智能体到商店中，你可以单击智能体名称，快速体验智能体的能力和效果。​

取消关注​

如果不再需要关注某个用户的公开动态，可以随时取消关注。​

  * 在关注区域取消关注：如果关注区域推送了一个你不再感兴趣的用户动态，你可以单击该用户头像，在其个人主页取消关注。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%271727%27%20height=%27249.9335705812574%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iMTcyNyIgaGVpZ2h0PSIyNDkuOTMzNTcwNTgxMjU3NCIgdmVyc2lvbj0iMS4xIiB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciPjwvc3ZnPg==)​

​

  * 通过关注列表取消关注：单击页面右下角个人图标，访问你的个人主页。单击关注人数即可查看你的关注列表，在列表中找到指定用户，并取消关注即可。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27500%27%20height=%27315.028901734104%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iNTAwIiBoZWlnaHQ9IjMxNS4wMjg5MDE3MzQxMDQiIHZlcnNpb249IjEuMSIgeG1sbnM9Imh0dHA6Ly93d3cudzMub3JnLzIwMDAvc3ZnIj48L3N2Zz4=)​

# 发布到企业商店 - 文档 - 扣子

发布到企业商店

企业商店是面向企业版用户的专属商店入口与发布渠道，用于在企业范围内上架与分发企业内部的低代码智能体与应用。企业商店中的低代码智能体和应用仅本企业的员工和访客可见、可访问，非本企业成员无法浏览或使用。​

使用限制​

说明

  * 套餐限制：仅企业旗舰版支持企业商店。​

  * 低代码应用不能同时发布扣子商店和企业商店。​

​

发布应用到企业商店​

1.

登录[扣子编程](<https://code.coze.cn/home>)。​

2.

在页面顶部空间列表中选择目标工作空间。​

3.

在项目开发页面，选择低代码应用。在页面右上角，单击发布。​

4.

选择企业商店渠道，先配置展示为桌面端或移动端，再勾选复选框。​

  * ​

单击发布。发布成功后单击完成。​

分享应用​

在扣子编程左侧导航栏选择更多 > 社区 > 企业项目，单击目标应用，在应用对话页面右上角单击分享图标，通过分享链接或微信二维码等方式分享给企业内其他成员。​

安装应用​

你可以将应用安装至本地电脑中，方便后续快速启动和直接使用该应用。​

在扣子编程左侧导航栏选择更多 > 社区 > 企业项目，单击目标应用，在应用对话页面右上角单击➕，在弹出的对话框中单击安装。​

​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27400%27%20height=%27101.73410404624276%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iNDAwIiBoZWlnaHQ9IjEwMS43MzQxMDQwNDYyNDI3NiIgdmVyc2lvbj0iMS4xIiB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciPjwvc3ZnPg==)​

从企业商店下架应用​

如果不再需要在企业商店中展示该应用，你可以选择将其下架。下架后，其他用户将无法再在企业商店中查看和使用该应用。​

说明

操作权限：企业超级管理员和管理员可下架企业商店中的所有应用，企业成员可下架自己的应用。​

​

在扣子编程左侧导航栏选择更多 > 社区 > 企业项目，单击目标应用，在应用对话页面右上角单击配置按钮，选择下架。​

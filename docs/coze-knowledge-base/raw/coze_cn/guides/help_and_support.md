# 获取帮助 - 文档 - 扣子

获取帮助

本文介绍在使用扣子过程中遇到问题时，可获取帮助的渠道。​

扣子助手​

建议优先通过扣子助手获取帮助。扣子助手是扣子团队提供的产品知识问答智能体，旨在于帮助扣子用户解决使用扣子过程中的咨询问题，尝试分析报错信息，协助处理异常场景。​

  * Web 端：​

  * 你可以在[扣子编程](<https://code.coze.cn/home>)或[扣子](<https://www.coze.cn/>)页面左下角单击你的头像 > 联系我们 > 帮助中心 > 意见反馈，随时唤起扣子助手。​

  * 和扣子助手对话，发送你的具体问题，扣子助手会尽力帮你解决。​

企业版技术支持​

企业版（标准版、旗舰版）付费套餐，由火山引擎提供售后服务。你可以通过[火山售后在线咨询](<https://console.volcengine.com/coze-pro/overview?entry=ConsoleSideBarAftermarket&openVcopilot={"query":"","displayMode":"fullscreen"}&vcopilotExtraInfo={"accountPlanName":"企业版"}>)提交工单，获取人工客服支持。提交工单之前，建议整理并收集报错场景、错误码等信息，以便工程师尽快定位你的问题。​

说明

  * 并非所有异常场景均可获取 Logid、错误码以供排查，你也可以提供异常场景的具体描述及截图，并提交反馈。​

  * 为企业标准版、原团队版提供工作日 10:00～19:00 的人工客服支持，为企业旗舰版、原企业版提供 7✖️24 小时的全天候人工客服支持。具体服务范围，请参考​客户服务。​

​

建议提供以下信息协助排查。​

​

场景​| 报错信息要求​  
---|---  
OpenAPI​| 使用 OpenAPI 时的问题排查，建议提供以下信息：​

  * Logid：在 API Response 的 Header 中查看 X-Tt-Logid 字段值，例如 20240708143040790E78F9318B35A2910B。你可以在使用 curl 发起请求时通过 -i 参数打印 Response Header 完整内容。​

  * 错误码：Response Body 中的 code、msg 字段值，例如 { "code": 700012006, "msg": "access token invalid" }。​

  
调试智能体​| 对于调试时发现的不符合预期的行为，可以在调试区获取 Logid。​​​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27222%27%20height=%27143%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iMjIyIiBoZWlnaHQ9IjE0MyIgdmVyc2lvbj0iMS4xIiB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciPjwvc3ZnPg==)​​  
其他场景​| 访问扣子编程的过程中，如果遇到异常报错场景，且反复重试仍然报错，可以根据页面提示复制错误信息，并联系扣子团队协助排查问题。​​​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27300%27%20height=%27123.52941176470587%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iMzAwIiBoZWlnaHQ9IjEyMy41Mjk0MTE3NjQ3MDU4NyIgdmVyc2lvbj0iMS4xIiB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciPjwvc3ZnPg==)​​​​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27299%27%20height=%27162%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iMjk5IiBoZWlnaHQ9IjE2MiIgdmVyc2lvbj0iMS4xIiB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciPjwvc3ZnPg==)​​说明错误 ID 有效期为 72 小时，失效后需要复现问题并获取新的 ID 再反馈。​​

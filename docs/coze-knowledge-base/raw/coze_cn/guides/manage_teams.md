# 创建并管理空间 - 文档 - 扣子

创建并管理空间

工作空间中的资源可以在空间成员中共享，如需和其他用户一起协同开发 AI 应用，需要先创建空间，并将邀请其他用户加入空间。​

创建空间​

说明

  * 套餐限制：仅企业版（企业标准版、企业旗舰版）支持创建工作空间。​

  * 角色权限：组织超级管理员和管理员。​

​

1.

在[扣子编程](<https://code.coze.cn/home>)左下角单击个人头像，选择企业，然后单击对应组织的设置图标。​

在创建新工作空间对话框，配置工作空间名称、描述和空间头像，并单击确认。​

  * 成功创建空间后，你可以在空间中创建智能体、插件等资源。​

转让空间​

如果你是空间所有者，可以在空间设置页面，将空间转移给其他成员。转移后指定的成员会成为该空间新的所有者，你将变为空间的管理员。​

注意

  * 转让所有权之后，空间所有者为此空间申请的个人访问密钥（PAT）会失效，无法通过这些密钥调用扣子 OpenAPI，请谨慎操作。​

  * 空间的所有权只能转移给空间内的其他内部用户，不支持转移给外部用户。关于内部用户和外部用户的定义，可以参考​内部用户和外部用户。​

​

登录[扣子编程](<https://code.coze.cn/home>)。​

2.

在左下角单击个人头像，选择企业，然后单击对应组织的设置图标。​

离开空间​

空间成员和管理员可以随时退出空间，并将自己在空间中的所有资源转移给其他成员。空间所有者退出空间之前需要将空间所有权转移给其他成员。​

1.

登录[扣子编程](<https://code.coze.cn/home>)。​

2.

在左下角单击个人头像，选择企业，然后单击对应组织的设置图标。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27311%27%20height=%27286%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iMzExIiBoZWlnaHQ9IjI4NiIgdmVyc2lvbj0iMS4xIiB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciPjwvc3ZnPg==)​

​

3.

在组织管理页面的顶部选择空间管理，然后单击目标工作空间对应的设置。​

​

3.

在顶部单击空间设置页签，单击离开空间。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27500%27%20height=%27260.11560693641616%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iNTAwIiBoZWlnaHQ9IjI2MC4xMTU2MDY5MzY0MTYxNiIgdmVyc2lvbj0iMS4xIiB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciPjwvc3ZnPg==)​

删除空间​

如果你是空间所有者，可以删除空间。​

注意

删除空间后，空间内的所有数据也会同步删除且不可恢复，请谨慎操作。​

​

1.

登录[扣子编程](<https://code.coze.cn/home>)。​

2.

在左下角单击个人头像，选择企业，然后单击对应组织的设置图标。​

​

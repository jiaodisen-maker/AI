# 添加访客到企业 - 文档 - 扣子

添加访客到企业

企业超级管理员或管理员可以将外部用户（访客）加入到企业中，以便协同开发和资源共享。​

说明

角色限制：企业超级管理员或管理员。​

​

费用说明​

访客在企业中使用工作空间内的资源时，均由企业版套餐的购买者（即超级管理员）支付，但在商店、企业商店和模板中消耗的积分，则抵扣个人版套餐的积分。​

设置允许访客加入企业​

1.

企业超级管理员或管理员登录[扣子编程](<https://code.coze.cn/home>)。​

2.

在左下角单击个人头像，选择企业> 团队与企业管理。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27267%27%20height=%27259%27/%3e)![](https://p9-arcosite.byteimg.com/https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/eb420c9c12cf4559ab2ea46162f4ca72~tplv-goo7wpa0wc-quality:q75.image)​

​

​

​

3.

在左侧导航栏选择企业成员管理，在顶部选择成员权限页签，关闭禁止访客加入企业右侧的开关，默认禁止访客加入企业。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27554%27%20height=%27166%27/%3e)![](https://p9-arcosite.byteimg.com/https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/9e9b6aef28c64b03adc55dd1330a01f7~tplv-goo7wpa0wc-quality:q75.image)​

添加访客​

方式一：单个添加访客​

1.

企业超级管理员或管理员登录[扣子编程](<https://code.coze.cn/home>)。​

2.

在左下角单击个人头像，选择企业> 团队与企业管理。​

  * ​

方式二：分享链接邀请访客加入​

1.

企业超级管理员或管理员登录[扣子编程](<https://code.coze.cn/home>)。​

2.

在左下角单击个人头像，选择企业> 团队与企业管理。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27267%27%20height=%27259%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iMjY3IiBoZWlnaHQ9IjI1OSIgdmVyc2lvbj0iMS4xIiB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciPjwvc3ZnPg==)​

​

​

​

3.

在左侧导航栏选择企业成员管理，在成员列表页签中，单击分享图标，通过分享链接，邀请访客加入企业。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27627%27%20height=%27235%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iNjI3IiBoZWlnaHQ9IjIzNSIgdmVyc2lvbj0iMS4xIiB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciPjwvc3ZnPg==)​

​

4.

访客访问对应的邀请链接，申请加入企业。​

5.

企业超级管理员或管理员在企业成员管理的申请管理页面，通过访客的加入申请。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27570%27%20height=%27141%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iNTcwIiBoZWlnaHQ9IjE0MSIgdmVyc2lvbj0iMS4xIiB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciPjwvc3ZnPg==)​

# 设置个人资料 - 文档 - 扣子

设置个人资料

注册扣子账号时，每个用户都需要填写自己的用户名和昵称。用户名和昵称是你在扣子社区中的身份。如果对用户名和昵称不满意，可以在个人信息页面中随时调整。个人信息页面还支持设置用户头像、签名信息、查看用户 UID等。​

设置个人资料​

通过以下步骤设置个人资料：​

1.

登录[扣子编程](<https://code.coze.cn/home>)。​

2.

在扣子编程左下角单击账号图标>设置。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27254%27%20height=%27414%27/%3e)![](https://p9-arcosite.byteimg.com/https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/abc18566cef34179af381f3d0aada0ee~tplv-goo7wpa0wc-quality:q75.image)​

​

3.

在系统设置页面，单击个人信息。页面中填写个人信息，并设置头像，然后单击保存。​

  * 个人信息页面支持设置头像、用户昵称、用户名和个性签名。暂不支持设置邮箱。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27417%27%20height=%27371%27/%3e)![](https://p9-arcosite.byteimg.com/https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/07b8261ef888424fb46807030e6f6d56~tplv-goo7wpa0wc-quality:q75.image)​

​

4.

设置完毕后，在个人主页中查看效果。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27487%27%20height=%27492%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iNDg3IiBoZWlnaHQ9IjQ5MiIgdmVyc2lvbj0iMS4xIiB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciPjwvc3ZnPg==)​

​

​

查看用户 UID​

你可以通过系统设置>个人信息页面，查看当前登录用户的 UID，UID 是你在扣子中的唯一身份标识。​

# 添加组织成员 - 文档 - 扣子

添加组织成员

企业旗舰版创建组织后，你可以将企业成员加入对应的组织。企业标准版无需执行该操作，用户加入企业时会自动加入默认组织。​

说明

  * 角色限制：组织超级管理员或管理员。​

  * 套餐限制：企业旗舰版。​

​

前提条件​

  * 已将成员添加至对应企业，具体操作请参见​添加员工到企业。​

  * 已创建对应的组织，具体操作请参见​操作步骤。​

邀请用户加入组织​

用户加入企业时将自动加入默认组织。组织超级管理员和管理员可以邀请员工（子用户）和外部成员（访客）加入对应的组织。成员加入对应组织后，其在默认组织中不会被删除。​

1.

在[扣子编程](<https://code.coze.cn/home>)左下角单击个人头像，选择企业，然后单击对应组织的设置图标。​

# 发布到商店 - 文档 - 扣子

发布到商店

商店是扣子编程官方为用户和开发者提供的交流与分享空间。应用商店拥有大量用户，将应用发布到扣子商店可以让更多潜在用户发现你的应用，提升曝光率。通过应用商店的推荐和搜索功能，应用可以获得更多的自然流量，增加应用使用率。本文介绍把应用发布到扣子商店的方法。​

前提条件​

要将应用发布到商店，必须满足以下条件：​

  * 待发布的应用至少包含一个工作流，且工作流配置了用户界面，可通过用户界面正常跑通工作流的基础流程。​

  * 扣子应用的发布者必须是扣子应用的所有者，协作者或管理员等角色均不支持发布应用。​

说明

建议经过充分的试运行后再发布应用，否则可能导致发布时打包失败，或应用线上运行异常。​

​

发布应用到扣子商店​

以下是将低代码应用发布到商店的详细步骤：​

1.

登录[扣子编程](<https://code.coze.cn/home>)。​

2.

在页面顶部空间列表中选择目标工作空间。 ​

3.

在项目开发页面，选择目标低代码应用，在应用编排页面右上角，单击发布。 ​

4.

在发布页面填写版本信息：​

  * 版本号：必填，必须是一个应用从未设置过的新版本号。​

  * 版本描述：可选，说明该版本更新的内容。​

5.

选择发布到扣子商店，先设置分类，再选中复选框。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27500%27%20height=%27280.3468208092485%27/%3e)![](https://p9-arcosite.byteimg.com/https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/b341789bd9f642be901f20846c395327~tplv-goo7wpa0wc-quality:q75.image)​

​

6.

单击发布。​

  * 发布后，你可以在当前页面查看发布环节的整体流程进度、最终发布状态。​

在商店更新应用​

如果想要更新已发布的应用，可以在商店更新应用：​

1.

在应用的编排页面右上角展开发布历史。​

2.

找到最近一次的商店发布记录，并单击立即使用。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27632%27%20height=%27277%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iNjMyIiBoZWlnaHQ9IjI3NyIgdmVyc2lvbj0iMS4xIiB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciPjwvc3ZnPg==)​

​

3.

在应用详情页面，单击右上角的配置按钮，然后选择修改编排。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27278%27%20height=%27392%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iMjc4IiBoZWlnaHQ9IjM5MiIgdmVyc2lvbj0iMS4xIiB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciPjwvc3ZnPg==)​

​

4.

在应用编辑页面完成更新后，单击发布。​

5.

重复上述发布到商店的流程后，商店中的应用也会更新到最新版本。​

从商店下架应用​

当你不希望在商店中展示发布的应用时，可以将其下架。具体步骤如下：​

1.

在应用的编排页面右上角展开发布历史。​

2.

找到最近一次的商店发布记录，并单击立即使用。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27548%27%20height=%27240%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iNTQ4IiBoZWlnaHQ9IjI0MCIgdmVyc2lvbj0iMS4xIiB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciPjwvc3ZnPg==)​

​

3.

在应用详情页面，单击右上角的配置按钮，然后选择下架。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27253%27%20height=%27356%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iMjUzIiBoZWlnaHQ9IjM1NiIgdmVyc2lvbj0iMS4xIiB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciPjwvc3ZnPg==)​

​

4.

在弹出的对话框中，单击确认。​

  * 下架后，其他用户将无法再在商店中查看和使用该应用。​

常见问题​

发布到扣子商店后，可以指定仅部分人可用吗？​

智能体或应用发布到扣子商店时，不支持设置指定用户访问。​

为什么发布到扣子商店提示“请先配置/授权”​

问题现象：​

发布应用到扣子商店时，无法选中复选框，提示“请先配置/授权”。​

​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27400%27%20height=%27105.43352601156069%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iNDAwIiBoZWlnaHQ9IjEwNS40MzM1MjYwMTE1NjA2OSIgdmVyc2lvbj0iMS4xIiB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciPjwvc3ZnPg==)​

​

解决方案：​

在扣子商店选项卡中先选择应用的分类，再选中复选框。​

​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27400%27%20height=%27224.27745664739885%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iNDAwIiBoZWlnaHQ9IjIyNC4yNzc0NTY2NDczOTg4NSIgdmVyc2lvbj0iMS4xIiB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciPjwvc3ZnPg==)​

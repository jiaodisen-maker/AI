# 探索商店 - 文档 - 扣子

探索商店

作品社区页、插件市场是扣子编程官方提供的用户与创建者的交流和分享基地。​

作品社区​

在作品社区页面，用户可以探索发现有用的低代码智能体、应用，而创建者可以将自己搭建的低代码智能体、应用发布到作品社区页面共享给更多的人使用。​

在[扣子编程](<https://code.coze.cn/home>)首页左侧的导航栏，选择更多 > 社区 > 作品社区即可访问作品社区。​

插件市场​

插件市场中展示扣子编程官方发布的插件、其他开发者创建的自定义插件。插件市场集合了各种功能丰富的插件资源，可以帮助你扩展智能体的功能，提高开发效率，降低开发的难度和成本。例如对于使用文本类大模型的智能体，因为模型不具备多模态能力，无法处理文件和图片相关的任务，例如阅读并总结 PDF，此时你可以为智能体添加链接读取等多模态插件，拓展智能体的能力边界。​

在[扣子编程](<https://code.coze.cn/home>)首页左侧的导航栏，选择更多 > 社区 > 插件市场查看已发布到插件市场的插件。​

单击目标插件，查看插件的使用说明。如果你想使用该插件，可直接单击添加到我的智能体，将该插件添加到选择的智能体中。​

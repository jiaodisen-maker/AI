# 查看页面导航 - 文档 - 扣子

查看页面导航

导航栏用于浏览和管理用户界面编辑器中的不同页面和图层。导航栏包含了一个页面列表，列表展示了项目中的所有页面。导航栏还提供了图层管理功能，图层管理支持控制不同元素的显示顺序和相互关系，对搭建复杂的页面至关重要。​

参考以下操作，查看页面导航。​

1.

登录[扣子编程](<https://code.coze.cn/home>)。​

2.

在页面顶部选择目标工作空间，然后在左侧导航栏中单击新建项目。​

3.

在低代码模式区域，将鼠标移动到更多，然后单击打开应用开发。​

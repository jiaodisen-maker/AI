# 邀请用户加入空间 - 文档 - 扣子

邀请用户加入空间

企业版中，空间所有者和管理员可以邀请其他扣子用户加入工作空间。​

功能简介​

在企业版中，空间所有者和管理员可以邀请企业成员（子用户）和外部用户（访客）加入工作空间。用户加入工作空间前，需先将其添加至对应企业和组织，具体操作请参见​添加员工到企业、​添加组织成员。​

说明

  * 套餐限制：企业版（企业标准版和企业旗舰版）。​

  * 角色限制：空间所有者和管理员。​

  * 访客限制：访客加入空间后，只能作为空间成员，不能作为空间管理员和空间所有者。​

  * 空间成员数量限制：空间的成员数量上限取决于套餐类型，企业标准版空间最多 50 人，企业旗舰版套餐空间人数无限制。​

​

设置允许外部用户加入空间​

在工作空间中，如果需要邀请外部用户加入空间，应由空间所有者或管理员关闭禁止外部用户加入当前空间。​

1.

登录[扣子编程](<https://code.coze.cn/home>)。​

2.

在左下角单击个人头像，选择企业，然后单击对应组织的设置图标。​

通过链接邀请用户​

空间所有者和空间管理员可以开启空间的邀请链接，其他扣子用户访问邀请链接来加入空间。此方式适用于不了解用户昵称或用户名、用户数量较多的情况，例如培训授课时邀请学员加入空间。​

说明

  * 空间邀请链接的有限期为 7 天，超期后需要重新复制链接。空间所有者或管理员也可以手动关闭分享链接，关闭后其他用户将无法通过链接加入空间。重新开启邀请链接后，之前的访问链接会失效。​

  * 空间的邀请链接是完全公开的，所有用户均可以通过邀请链接加入空间。为保障信息安全和数据安全，需要注意邀请链接的传播范围，或者在成员与设置 > 空间设置页面关闭禁止外部用户加入当前空间。​

直接添加用户​

如果已获取了扣子用户的昵称、用户名或火山成员名，可以直接将其加入工作空间。​

1.

登录[扣子编程](<https://code.coze.cn/home>)。​

2.

在左下角单击个人头像，选择企业，然后单击对应组织的设置图标。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27311%27%20height=%27286%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iMzExIiBoZWlnaHQ9IjI4NiIgdmVyc2lvbj0iMS4xIiB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciPjwvc3ZnPg==)​

​

3.

在组织管理页面的顶部选择空间管理，然后单击目标工作空间对应的设置。​

​

3.

在顶部单击成员管理页签，在右上角单击 \+ 添加成员。​

4.

输入扣子用户的用户名、用户昵称或火山成员名搜索用户，并设置用户角色。​

  * 用户角色的差异可参考​设置空间成员角色。​

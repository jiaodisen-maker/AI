# 发布到 OPPO 智能体广场 - 文档 - 扣子

发布到 OPPO 智能体广场

开发者可以将智能体发布到 OPPO 智能体广场，以便用户通过 OPPO 智能体广场搜索并使用智能体，从而提升智能体的曝光度和市场覆盖范围。本文详细介绍了将智能体发布至 OPPO 智能体广场的操作流程。​

费用说明​

  * 智能体发布至 OPPO 智能体广场后，用户使用该智能体产生的费用由 OPPO 承担。​

  * 如果智能体使用方舟接入点的模型，用户使用该智能体产生的方舟模型 Token 费用由方舟模型接入点的创建者承担。​

使用限制​

功能限制：不支持语音通话和触发器功能。​

添加 OPPO 智能体广场渠道​

在发布渠道管理页面添加 OPPO 智能体广场渠道，工作空间中的用户才能将智能体发布至 OPPO 智能体广场渠道。​

企业版​

说明

角色限制：企业的超级管理员和管理员。​

​

1.

在[扣子编程企业管理页面](<https://docs.coze.cn/guides/admin.coze.cn>)的左侧导航栏选择发布渠道限制，在公共渠道区域开启OPPO 智能体广场渠道。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27400%27%20height=%27149.76303317535542%27/%3e)![](https://p9-arcosite.byteimg.com/https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/e670e42073a741f3979a625803c173f4~tplv-goo7wpa0wc-quality:q75.image)​

​

2.

在左侧导航栏选择企业组织管理，将鼠标悬停至目标组织的卡片，单击当前组织设置。​

3.

在顶部选择发布渠道管理页签，鼠标悬停在 OPPO 智能体广场卡片上，单击空间配置，单击目标工作空间右侧的开关开启渠道。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27500%27%20height=%27313.2387706855792%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iNTAwIiBoZWlnaHQ9IjMxMy4yMzg3NzA2ODU1NzkyIiB2ZXJzaW9uPSIxLjEiIHhtbG5zPSJodHRwOi8vd3d3LnczLm9yZy8yMDAwL3N2ZyI+PC9zdmc+)​

  * 只有给对应工作空间授权 OPPO 智能体广场发布渠道，工作空间成员才能将智能体发布至该渠道。​

​

发布智能体到 OPPO 智能体广场​

1.

在顶部空间列表选择目标工作空间，在左侧导航栏选择项目开发，单击目标智能体。​

  * 说明

为了方便用户在 OPPO 智能体广场中快速找到你的智能体，建议为智能体取一个独特且易于识别的名称。​

​

2.

在智能体编排页面的右上角单击发布，发布平台选择 OPPO 智能体广场，单击发布。​

在 OPPO 智能体广场使用智能体​

用户打开 OPPO 智能体广场 APP，通过 OPPO 软件商店或底部的智能体入口，查找到对应的智能体，单击使用，即可与该智能体进行对话。​

相关操作​

下架智能体​

如果不再需要在该渠道中展示智能体，你可以选择将其下架。下架的操作步骤请参见​下架智能体。​

常见问题​

发布到 OPPO 智能体广场需要审核吗？​

目前，智能体发布 OPPO 智能体广场后，暂时不需要审核。​

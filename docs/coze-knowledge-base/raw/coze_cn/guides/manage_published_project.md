# 管理发布产物 - 文档 - 扣子

管理发布产物

通过扣子编程，你可以搭建各种基于大模型的 AI 项目，例如智能体、应用、工作流。扣子编程提供 AI 项目的发布管理能力，支持查看工作空间中已发布的智能体、应用或工作流，查看其消息日志、分析数据、触发器执行记录，也可以一键从商店中下架智能体、应用。​

查看发布列表​

编排并发布智能体、应用或工作流之后，你可以在工作空间的发布管理页面查看发布产物列表，列表中展示发布产物的创建人、已发布平台等信息。​

1.

登录[扣子编程](<https://code.coze.cn/home>)。​

2.

在左下角单击个人头像，选择企业，然后单击对应组织的设置图标。​

  * ​

​

3.

在组织管理页面的顶部选择空间管理，然后单击目标工作空间对应的设置。​

​

3.

在顶部选择发布管理页签，在工作空间的发布管理页面查看发布产物列表，列表中展示发布产物的创建人、已发布平台等信息。​

查看消息日志​

在智能体、应用或工作流中，每条消息回复都会生成一条消息日志，这个消息日志详细记录了其回复问题的编排步骤和过程。消息日志帮助你了解智能体、应用或工作流的推理过程，以便你进行针对性的分析和优化。​

1.

登录[扣子编程](<https://code.coze.cn/home>)。​

2.

在左下角单击个人头像，选择企业，然后单击对应组织的设置图标。​

  * ​

3.

在组织管理页面的顶部选择空间管理，然后单击目标工作空间对应的设置。​

​

3.

在顶部选择发布管理页签，选择智能体、应用或工作流，可查看对应发布产物的运行日志列表。页面右侧的统计区域展示筛选范围内运行日志的相关统计数据。关于运行日志和统计数据的详细说明，可参考​查看消息列表。​

下架智能体或应用​

下架智能体​

支持的渠道：目前支持从扣子官方渠道及自定义渠道下架智能体，但不包括豆包渠道。​

操作步骤：​

1.

登录[扣子编程](<https://code.coze.cn/home>)。​

2.

在左下角单击个人头像，选择企业，然后单击对应组织的设置图标。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27311%27%20height=%27286%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iMzExIiBoZWlnaHQ9IjI4NiIgdmVyc2lvbj0iMS4xIiB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciPjwvc3ZnPg==)​

​

3.

在组织管理页面的顶部选择空间管理，然后单击目标工作空间对应的设置。​

​

3.

在顶部选择发布管理页签，在目标智能体右侧单击下架，选择需要下架的渠道，单击下架，在确认对话框中单击下架。​

  * 说明

    * 仅智能体所有者可以下架智能体。​

    * 目前暂不支持通过该入口下架发布到豆包的智能体，若需在豆包中删除扣子智能体，可参考​在豆包中删除智能体。​

​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27600%27%20height=%27339.88439306358384%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iNjAwIiBoZWlnaHQ9IjMzOS44ODQzOTMwNjM1ODM4NCIgdmVyc2lvbj0iMS4xIiB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciPjwvc3ZnPg==)​

下架应用​

支持的渠道：目前仅支持从扣子商店及扣子空间扩展库下架应用。​

操作步骤：​

1.

登录[扣子编程](<https://code.coze.cn/home>)。​

2.

在左下角单击个人头像，选择企业，然后单击对应组织的设置图标。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27311%27%20height=%27286%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iMzExIiBoZWlnaHQ9IjI4NiIgdmVyc2lvbj0iMS4xIiB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciPjwvc3ZnPg==)​

​

3.

在组织管理页面的顶部选择空间管理，然后单击目标工作空间对应的设置。​

​

3.

在顶部选择发布管理页签，单击应用名称，在右上角单击管理，选择扣子商店或扣子空间扩展库，单击下架，在确认对话框中单击下架。​

  * 说明

仅应用所有者可以下架应用。​

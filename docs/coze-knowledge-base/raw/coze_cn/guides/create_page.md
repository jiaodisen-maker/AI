# 创建页面 - 文档 - 扣子

创建页面

使用用户界面编辑器搭建用户界面的第一步就是创建页面。你可以选择创建一个空白页，然后再通过拖放组件逐步搭建用户界面。你也可以选取一个预设模板来创建页面，并根据具体的业务需求进行个性化调整。单个低代码应用最多可以创建 20 个 UI 页面。​

创建空白页面​

系统默认创建一个Home Page页面，你可以对该页面执行重命名或删除操作。你也可以创建一个新空白页面，然后拖放组件到空白页面的画布中。​

参考以下操作，创建一个空白页面。​

1.

登录[扣子编程](<https://code.coze.cn/home>)。​

2.

在页面顶部选择目标工作空间，然后在左侧导航栏中单击新建项目。​

3.

在低代码模式区域，将鼠标移动到更多，然后单击打开应用开发。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27432%27%20height=%27255%27/%3e)![](https://p9-arcosite.byteimg.com/https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/6eb5b74cc7b74f2ea893f0ebc62c3b1b~tplv-goo7wpa0wc-quality:q75.image)​

​

  * ​

​

4.

在应用模板页面，单击空白应用。​

5.

单击用户界面页签，选择页面类型，然后单击开始搭建。​

  * 页面类型包括网页端页面、小程序和 H5 端页面，选择页面类型后，不支持修改。​

6.

在左侧面板，单击结构页签，然后单击页面列表右上角的 +，新建空白页面。​

  * 每单击一次 +，都会新建一个新空白页面。如果需要更改页面名称，请双击页面标题，输入新名称，然后按回车键或点击页面其他区域以保存新名称。​

使用模板创建页面​

用户界面编辑器提供了多种界面模板，例如导航模版、横幅模版、列表模版和卡片模版，你可以基于模板创建页面，并根据实际需求修改页面。​

1.

在用户界面页签，单击模板。​

2.

在模版栏，选择目标模板。​

3.

在弹出的对话框中，单击确认。​

设置页面路径​

为了确保用户界面能够被正确引用和访问，系统为每个页面自动生成了一个路径，你可以根据实际需求修改页面路径。​

1.

在用户界面页签，单击导航。​

2.

在页面列表，选择需要设置路径的页面，然后单击属性面板右上角的设置图标。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27538%27%20height=%27232%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iNTM4IiBoZWlnaHQ9IjIzMiIgdmVyc2lvbj0iMS4xIiB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciPjwvc3ZnPg==)​

​

3.

设置页面的路径，然后单击确认。​

  * 仅支持字母、数字、下划线，且不能以数字开头。​

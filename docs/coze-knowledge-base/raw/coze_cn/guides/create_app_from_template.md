# 使用低代码应用模板 - 文档 - 扣子

使用低代码应用模板

扣子编程的低代码应用模板是一个完整的可运行的低代码应用。你可以通过使用应用模板快速搭建一个自己的低代码应用。​

参考以下操作，使用应用模板创建一个低代码应用。​

1.

登录[扣子编程](<https://code.coze.cn/home>)。​

2.

在页面顶部选择目标工作空间，然后在左侧导航栏中单击新建项目。​

3.

在低代码模式区域，将鼠标移动到更多，然后单击打开应用开发。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27432%27%20height=%27255%27/%3e)![](https://p9-arcosite.byteimg.com/https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/6eb5b74cc7b74f2ea893f0ebc62c3b1b~tplv-goo7wpa0wc-quality:q75.image)​

​

  * ​

​

4.

在应用模板页面，找到匹配的模板，然后单击预览体验应用功能。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27403%27%20height=%27250%27/%3e)![](https://p9-arcosite.byteimg.com/https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/147a5202de2240daad755c068da2ccc4~tplv-goo7wpa0wc-quality:q75.image)​

​

5.

在打开的应用预览页面，查看和体验模板能力，然后单击复制。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27535%27%20height=%27251%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iNTM1IiBoZWlnaHQ9IjI1MSIgdmVyc2lvbj0iMS4xIiB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciPjwvc3ZnPg==)​

​

6.

输入应用名称并选择所属空间，然后单击确认。​

创建完成后，你会直接进入到应用集成开发环境。你就可以根据自己的实际需求，对复制后的应用配置进行修改了。​

# 企业基础设置 - 文档 - 扣子

企业基础设置

超级管理员可以修改企业的设置，包括修改名称和头像，查看套餐信息并续费。​

修改企业的名称与头像​

1.

企业超级管理员或管理员登录[扣子编程](<https://code.coze.cn/home>)。​

2.

在左下角单击个人头像，选择企业> 团队与企业管理。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27267%27%20height=%27259%27/%3e)![](https://p9-arcosite.byteimg.com/https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/eb420c9c12cf4559ab2ea46162f4ca72~tplv-goo7wpa0wc-quality:q75.image)​

​

​

​

2.

在左侧导航栏选择企业设置页签，编辑头像和名称。​

​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27505%27%20height=%27238%27/%3e)![](https://p9-arcosite.byteimg.com/https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/6268a4349f0c45278e42e94fc6aa17ae~tplv-goo7wpa0wc-quality:q75.image)​

​

将扣子 Logo 替换为企业 Logo​

扣子左侧导航栏中的 Logo 默认为扣子的 Logo，扣子企业旗舰版用户支持将平台默认的扣子 Logo 替换为企业 Logo，即企业自定义的头像，以增强品牌识别度和企业形象展示。​

1.

企业超级管理员或管理员登录[扣子编程](<https://code.coze.cn/home>)。​

2.

在左下角单击个人头像，选择企业> 团队与企业管理。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27267%27%20height=%27259%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iMjY3IiBoZWlnaHQ9IjI1OSIgdmVyc2lvbj0iMS4xIiB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciPjwvc3ZnPg==)​

​

​

​

3.

在顶部选择企业设置页签，设置企业的自定义头像后，打开将扣子 Logo 替换为企业 Logo 右侧的开关。扣子会自动将左上角的扣子 Logo 替换为企业自定义头像。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27599%27%20height=%27292%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iNTk5IiBoZWlnaHQ9IjI5MiIgdmVyc2lvbj0iMS4xIiB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciPjwvc3ZnPg==)​

​

查看或修改企业的登录信息​

企业的超级管理员或管理员可以在火山引擎扣子控制台中查看或修改扣子登录信息，包括别名、默认域名等信息。​

其中，企业超级管理员可以在扣子编程的添加新成员对话框中，单击创建员工用户账号，跳转到火山引擎扣子控制台进行操作，无需通过火山引擎账号进行登录。具体操作，请参考​步骤一：创建成员。​

​

​

查看套餐信息并续费​

超级管理员可以在企业设置下查看基本信息，包括当前套餐、创建时间和到期时间，并进行续费。​

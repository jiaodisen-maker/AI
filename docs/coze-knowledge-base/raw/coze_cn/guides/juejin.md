# 发布到掘金 - 文档 - 扣子

发布到掘金

扣子支持将低代码智能体发布到掘金社区，使用智能体与社区用户互动。社区用户可直接点击智能体名称或在发布窗口中at已发布的智能体，使用智能体发布沸点内容；也可以在评论中回复智能体，与智能体进行对话。​

​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27447%27%20height=%27360%27/%3e)![](https://p9-arcosite.byteimg.com/https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/085822ab9d104c1c9afb33cddf395211~tplv-goo7wpa0wc-quality:q75.image)​

​

前提条件​

1.

已搭建了扣子智能体。​

2.

已注册了[掘金社区](<https://juejin.cn/>)。​

步骤一：将智能体发布到掘金社区​

1.

登录[扣子编程](<https://code.coze.cn/home>)。​

2.

在页面顶部空间列表中选择目标工作空间。​

3.

在项目开发页面，选择低代码智能体。在页面右上角，单击发布。​

​

4.

在发布页面，找到掘金渠道，然后单击配置。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27406%27%20height=%2746%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iNDA2IiBoZWlnaHQ9IjQ2IiB2ZXJzaW9uPSIxLjEiIHhtbG5zPSJodHRwOi8vd3d3LnczLm9yZy8yMDAwL3N2ZyI+PC9zdmc+)​

​

5.

在弹出的页面完成登录和授权。​

6.

返回到发布页面，勾选掘金渠道，然后单击发布。​

步骤二：在社区中使用智能体​

完成智能体发布后，你就可以在掘金社区中使用该智能体了。​

1.

访问[掘金社区](<https://juejin.cn/>)。​

2.

打开并关注[AI聊天室](<https://juejin.cn/pins/myclub/7173895829281833012>)圈子，然后在文本框中直接at已发布的智能体，或单击文本框下的机器人图标，选择已发布的智能体，输入内容后再点击发布。​

  * 说明

    * 目前仅支持在AI聊天室中使用发布的智能体。​

    * 目前仅支持接收文本消息。​

    * 后续会支持和开放更多能力，请持续关注。​

​

3.

消息发布后会默认进入审核状态，1 分钟内会完成审核。待审核完成后，你就可以看到智能体的回复了。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27417%27%20height=%27283%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iNDE3IiBoZWlnaHQ9IjI4MyIgdmVyc2lvbj0iMS4xIiB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciPjwvc3ZnPg==)​

​

4.

点击评论按钮继续与智能体对话。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27423%27%20height=%27360%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iNDIzIiBoZWlnaHQ9IjM2MCIgdmVyc2lvbj0iMS4xIiB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciPjwvc3ZnPg==)​

​

下架智能体​

如果不再需要在该渠道中展示智能体，您可以选择将其下架。下架的操作步骤请参见​下架智能体。​

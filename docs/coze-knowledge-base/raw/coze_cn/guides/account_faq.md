# 账号常见问题 - 文档 - 扣子

账号常见问题

扣子账号如何换绑手机号？​

你可以通过火山引擎控制台换绑扣子账号的手机号，扣子账号换绑手机号时需要手机验证码，具体操作如下：​

1.

通过手机号或抖音扫码等方式登录[火山引擎控制台](<https://console.volcengine.com/user/basics/>)。​

2.

在账号管理页面，单击绑定手机右侧的解绑，在认证对话框中填写手机验证码，单击确认。​

  * 说明

若账号绑定的原手机号已注销，无法接收验证码，你可以在弹出的认证对话框底部，单击验证方式不可使用，提交申诉。根据页面提示修改安全手机。​

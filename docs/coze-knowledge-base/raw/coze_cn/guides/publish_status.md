# 查看应用发布状态 - 文档 - 扣子

查看应用发布状态

发布应用后，你可以在发布页面查看当前版本的发布状态，也支持通过查看发布历史查看应用每一次发布的审核与发布结果。以下是查看发布历史的具体操作步骤：​

1.

登录[扣子编程](<https://code.coze.cn/home>)。​

2.

在页面顶部空间列表中选择目标工作空间。 ​

3.

在项目开发页面，选择目标低代码应用，进入应用的编排页面。​

4.

在页面右上方单击版本记录图标，查看发布历史。​

  * 可以选择特定发布版本查看发布状态。​

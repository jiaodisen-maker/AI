# 管理数据源权限 - 文档 - 扣子

管理数据源权限

从飞书、Notion 、微信公众号等渠道导入知识库文件时，需要数据源侧的授权，例如飞书账号授权扣子编程读取本账号的公开文档。授权后可以随时取消授权，也可以添加其他账号的授权。​

添加授权​

参考以下操作，为知识库添加数据源侧的授权。​

1.

登录[扣子编程](<https://code.coze.cn/home>)。​

​

2.

在扣子编程左下角，单击头像，然后单击账户设置。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27134%27%20height=%27279%27/%3e)![](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/fa22984bb50b4be28b315d7b5fe159fa~tplv-goo7wpa0wc-quality:q75.image)​

​

3.

在数据源页面，找到需要授权的数据源，并单击其右侧的授权。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27626%27%20height=%27225%27/%3e)![](https://p9-arcosite.byteimg.com/https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/206be79595a44cc9bdec85e2eed98427~tplv-goo7wpa0wc-quality:q75.image)​

​

  * 飞书授权：确认授权的飞书账号无误后，单击授权。​

  * Notion 授权：单击选择页面，勾选允许扣子编程访问的页面，然后单击允许访问。​

4.

授权后，即可在数据源中查看刚刚添加的账号。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27624%27%20height=%27246%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iNjI0IiBoZWlnaHQ9IjI0NiIgdmVyc2lvbj0iMS4xIiB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciPjwvc3ZnPg==)​

​

  * 在知识库中添加内容时，也可以切换账号，选择另一个账号中的文档。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27418%27%20height=%27226%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iNDE4IiBoZWlnaHQ9IjIyNiIgdmVyc2lvbj0iMS4xIiB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciPjwvc3ZnPg==)​

移除授权​

如果你不需要将飞书或 Notion 平台的文件导入到知识库，你可以移除相应的授权。​

参考以下操作，移除授权：​

1.

在数据源页面，将鼠标悬浮至需要移除授权的账号区域，然后单击其右侧的移除图标。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27536%27%20height=%27210%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iNTM2IiBoZWlnaHQ9IjIxMCIgdmVyc2lvbj0iMS4xIiB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciPjwvc3ZnPg==)​

​

2.

在弹出的对话框中，单击确认。​

  * 移除飞书账号：移除后，与该账号关联的文档将无法更新内容。​

  * 移除 workspace：移除后，从该 workspace 导入和创建的 Units 的定期更新将被暂停，如要恢复，需要重新绑定更新同步到 workspace。​

  * 你也可以勾选同时删除已添加的文件和向量块，然后单击确认，系统会删除该账号下已经导入到知识库的文件。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27407%27%20height=%27220%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iNDA3IiBoZWlnaHQ9IjIyMCIgdmVyc2lvbj0iMS4xIiB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciPjwvc3ZnPg==)​

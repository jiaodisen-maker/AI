# 发布到小米应用商店 - 文档 - 扣子

发布到小米应用商店

开发者可以将智能体发布到小米应用商店，以便用户通过小米应用商店搜索并使用智能体，从而提升智能体的曝光度和市场覆盖范围。本文详细介绍了将智能体发布至小米应用商店的操作流程。​

费用说明​

智能体发布至小米应用商店后，用户使用该智能体产生的费用由智能体开发者承担。​

使用限制​

如果智能体中添加了触发器，发布小米应用商店后，触发器不生效。​

添加小米应用商店渠道​

在发布渠道管理页面添加小米应用商店渠道，工作空间中的用户才能将智能体发布至小米应用商店。​

发布智能体到小米应用商店​

1.

在顶部空间列表选择目标工作空间，在左侧导航栏选择项目开发，单击目标智能体。​

  * 说明

为了方便用户在小米应用商店中快速找到你的智能体，建议为智能体取一个独特且易于识别的名称。​

​

2.

在智能体编排页面的右上角单击发布，发布平台选择小米应用商店，单击发布。在弹出的成本提示确认对话框中单击确认。​

在小米应用商店使用智能体​

审核通过后，用户打开小米应用商店 APP，单击底部的智能体入口，在 AI 智能体专区搜索对应的智能体，单击使用，使用小米账号登录后即可与该智能体进行对话。​

相关操作​

下架智能体​

如果不再需要在该渠道中展示智能体，你可以选择将其下架。下架的操作步骤请参见​下架智能体。​

常见问题​

发布到小米应用商店需要审核吗？​

智能体发布小米应用商店后，小米会对智能体进行审核，审核周期预计 3 个工作日，请耐心等待审核结果。​

审核通过后，智能体将在小米应用商店中上线。你可以通过在小米应用商店内搜索智能体名称来判断审核是否通过。如果搜索结果中显示该智能体，则表示审核通过，如果搜索不到，则表示审核未通过。​

如果审核不通过，可以根据​扣子平台内容发布标准和规范检查并修改智能体配置，确保内容符合小米平台的要求，然后重新提交审核。如果确认内容没有问题，但审核仍未通过，可[联系小米客服](<https://account.xiaomi.com/fe/service/login/password?_group=DEFAULT&_locale=zh_CN&sid=mideveloper&qs=%3Fcallback%3Dhttps%253A%252F%252Fdev.mi.com%252Fsts%253Fsign%253Duzw6KrLEwxOoc97Yu51MM2avBPU%25253D%2526followup%253Dhttps%25253A%25252F%25252Fdev.mi.com%25252Fcallback%25253FcallbackUrl%25253Dhttps%2525253A%2525252F%2525252Fwww.sobot.com%2525252Fchat%2525252Fpc%2525252Fv2%2525252Findex.html%2525253Fsysnum%2525253D5d7e332c4f994cf295cbfb0e81851038%26sid%3Dmideveloper%26_locale%3Dzh_CN%26_group%3DDEFAULT&callback=https://dev.mi.com/sts?sign=uzw6KrLEwxOoc97Yu51MM2avBPU%3D&followup=https%3A%2F%2Fdev.mi.com%2Fcallback%3FcallbackUrl%3Dhttps%253A%252F%252Fwww.sobot.com%252Fchat%252Fpc%252Fv2%252Findex.html%253Fsysnum%253D5d7e332c4f994cf295cbfb0e81851038&_sign=zcgqpW5mKG48sON9TJLg7oI6BYQ=&serviceParam={"checkSafePhone":false,"checkSafeAddress":false,"lsrp_score":0.0}&showActiveX=false&theme=&needTheme=false&bizDeviceType=>)咨询。​

智能体为什么被下架了？​

小米会定期巡查已上架的智能体。若发现智能体存在功能缺陷、违规内容等不符合审核标准的问题，为保障用户体验，小米将对其执行下架操作。​

# 扣子个人版 3 倍积分膨胀限时活动细则 - 文档 - 扣子

扣子个人版 3 倍积分膨胀限时活动细则

一、活动概述​

为回馈广大用户长期支持，扣子官方推出限时积分膨胀活动，活动期间个人高阶版和旗舰版用户每月可享受 3 倍积分权益，助力用户获得更充足的资源使用额度。​

二、活动对象​

仅限个人高阶版和个人旗舰版用户参与，企业版等其他订阅套餐不纳入本次活动范围。​

三、活动时间​

活动已正式上线，将于2026年4月16日晚24点结束。活动结束后，每月将不再继续赠送相应数量积分。​

四、活动核心规则​

1\. 积分膨胀计算方式​

活动有效期内，符合条件的用户每月可额外获得 2 倍于基础套餐积分的活动加赠，实现总计 3 倍积分权益：​

​

套餐类型​| 基础套餐积分​| 活动加赠积分​| 每月总计可获得积分​  
---|---|---|---  
个人高阶版​| 9.9万​| 19.8万​| 29.7万​  
个人旗舰版​| 19.9万​| 39.8万​| 59.7万​  
  
​

2\. 积分性质与有效期​

  * 本次加赠的积分为活动专属积分，其有效期与当月套餐有效期保持一致，到期未使用的活动积分将自动清零。​

  * 积分消耗顺序：优先消耗基础套餐积分，再消耗活动积分，最后消耗增购积分。​

五、适用用户范围​

  * 存量用户：活动开始时已处于个人高阶版/旗舰版生效状态的用户，扣子将一次性发放对应档位的活动积分，积分有效期为1个月。​

  * 增量用户：在活动期间新购、或从低版本升配到个人高阶版/旗舰版的用户，在订阅周期生效时将自动获得当月的活动加赠积分。​

  * 包年付费用户：后续每个月计费周期生效时，如果活动仍未结束，将按月发放对应档位的活动积分；若活动已结束，则不再发放活动积分。​

六、常见场景权益说明​

​

用户类型​| 操作行为​| 权益说明​  
---|---|---  
个人免费版/进阶版用户​| 升配至高阶版/旗舰版​| 升配成功后立即生效，若升配时活动仍在有效期内，按新套餐标准享受3倍积分权益。​  
个人高阶版/旗舰版用户​| 续费（连续包月/包年）​| 续费成功后，若新计费周期开始时活动仍在有效期内，可继续享受 3 倍积分权益；若活动已结束，新周期不再发放活动积分。​  
个人高阶版/旗舰版用户​| 降配至免费版/进阶版​| 降配将在当前计费周期结束后生效，新周期开始后不再享受积分膨胀活动。​  
个人高阶版/旗舰版用户​| 退订​| 当前订阅周期内仍可正常使用已发放的活动积分权益，周期结束后套餐回退至免费版，所有订阅积分（含活动积分）自动失效。​  
个人高阶版/旗舰版用户​| 迁移至企业版​| 个人版与企业版为两套独立付费体系，迁移后将失去个人版活动资格，不再享受积分膨胀权益。​  
企业版所有用户​| 任何操作​| 企业版用户不参与本次个人版积分膨胀活动，所有操作均遵循企业版原有商业化规则。​  
  
​

七、其他说明​

1.

本次活动加赠的积分，其有效期不受活动结束的影响，你可以在积分明细中查看详情。​

2.

本活动最终解释权归扣子 Coze 官方所有，活动规则如有调整将提前通过官方渠道公告。​

# 设置空间成员权限 - 文档 - 扣子

设置空间成员权限

你可以灵活配置工作空间成员的资源创建与发布权限，满足多样化协作需求。​

说明

  * 套餐限制：扣子企业版（企业标准版和企业旗舰版）。​

  * 角色限制：空间所有者和空间管理员。​

​

功能简介​

空间所有者和空间管理员可通过成员权限管控，对工作空间成员的资源创建权限与发布权限进行精细化管理，减少非必要成员操作导致的资源混乱或风险，从而提升资源管理的规范性与安全性。具体包括：​

  * 资源创建权限：默认允许工作空间内的所有成员创建智能体、应用、知识库、数据库、插件。也可以设置仅允许空间所有者和管理员创建对应的资源。工作流、音色和卡片不受此限制。​

  * 资源发布权限：默认允许工作空间内的所有成员发布智能体和应用，也可以配置仅限白名单成员发布。​

资源发布权限​

默认允许工作空间内的所有成员发布智能体和应用，适用于组织成员高度信任且协作紧密的场景，可快速推动项目进展。若需限制发布权限以保障项目质量和安全性，可添加允许发布的成员名单，实现更精细的权限管理。​

1.

登录[扣子编程](<https://code.coze.cn/home>)。​

2.

在左下角单击个人头像，选择企业，然后单击对应组织的设置图标。​

资源创建权限​

默认允许工作空间内的所有成员创建智能体、应用、知识库、数据库、插件。若需限制仅允许空间所有者和管理员创建对应类型的资源，你可以关闭对应资源类型的创建权限。​

1.

登录[扣子编程](<https://code.coze.cn/home>)。​

2.

在左下角单击个人头像，选择企业，然后单击对应组织的设置图标。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27311%27%20height=%27286%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iMzExIiBoZWlnaHQ9IjI4NiIgdmVyc2lvbj0iMS4xIiB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciPjwvc3ZnPg==)​

​

3.

在组织管理页面的顶部选择空间管理，然后单击目标工作空间对应的设置。​

​

3.

在顶部选择权限管理页签，单击资源创建页签，设置资源创建权限：​

  * 允许空间成员创建资源：开启对应资源类型右侧的开关。​

  * 仅允许空间所有者和管理员创建资源：关闭对应资源类型右侧的开关，在确认对话框中单击关闭。​

  * ​

新建、编辑文件夹权限​

默认仅工作空间所有者和管理员可新建、编辑文件夹。如果需要允许空间内成员新建、编辑文件夹，你可以关闭新建、编辑文件夹的权限。​

1.

登录[扣子编程](<https://code.coze.cn/home>)。​

2.

在左下角单击个人头像，选择企业，然后单击对应组织的设置图标。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27311%27%20height=%27286%27/%3e)![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iMzExIiBoZWlnaHQ9IjI4NiIgdmVyc2lvbj0iMS4xIiB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciPjwvc3ZnPg==)​

​

3.

在组织管理页面的顶部选择空间管理，然后单击目标工作空间对应的设置。​

​

3.

在顶部选择空间设置页签，设置文件夹编辑权限：​

  * 允许空间成员新建、编辑文件夹：关闭右侧的开关。​

  * 仅允许空间所有者和管理员新建、编辑文件夹：开启右侧的开关。​

常见问题​

访客能创建文件夹吗？​

如果空间所有者设置了允许空间成员新建、编辑文件夹，访客加入工作空间后，可以新建文件夹。​

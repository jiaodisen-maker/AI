# 文件夹管理 - 文档 - 扣子

文件夹管理

你可以通过文件夹对项目开发页面中的应用和智能体进行归类，提升查找效率。例如教师可以为每个课时创建文件夹，以便管理不同课时的教学内容。​

使用限制​

说明

  * 角色限制：默认仅空间所有者和管理员可以创建、编辑和删除文件夹。如需允许空间成员创建和编辑文件夹，请在空间设置页面开启相关权限，具体步骤参见​新建、编辑文件夹权限。​

  * 数量限制：单个工作空间最多创建 1000 个文件夹。​

  * 文件夹层级：最多 10 层。​

​

操作步骤​

1.

创建文件夹。​

  * 在扣子编程顶部选择对应工作空间，在左侧导航栏选择项目管理，单击右上角的新增文件夹，输入文件夹名称并确认创建。​

选择目标文件夹，单击更多选项，选择删除。​

# 模型下线通知 - 文档 - 扣子

模型下线通知

本文罗列了扣子编程官方模型服务的下线计划。​

影响说明​

模型下线后，使用该模型的线上服务（包括智能体、工作流、应用等）将无法正常运行。​

切换模型​

请你在模型下线前完成模型切换，避免服务中断。给你带来的不便，敬请谅解。​

  * 编程项目：工作空间的所有者或管理员可以快速定位当前工作空间下所有使用该模型的 AI 编程项目，并批量为这些项目的线上版本切换模型。具体操作，请参考​如何批量切换待下架模型？。​

  * 低代码项目：​

  * 项目的创建者可以在用量详情图表中，快速定位调用了待下架模型的智能体或工作流，并逐个为它们切换模型。​

  * 工作空间的所有者或管理员可以在用量详情图表中，快速定位当前工作空间下所有使用该模型的智能体或工作流，并批量为这些项目的线上版本切换模型。​

  * 具体操作，请参考​如何快速切换待下架模型？。​

如有疑问，可联系扣子技术支持获取帮助。​

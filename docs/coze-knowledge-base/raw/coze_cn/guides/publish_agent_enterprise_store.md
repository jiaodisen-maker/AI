# 发布到企业商店 - 文档 - 扣子

发布到企业商店

企业商店是面向企业版用户的专属商店入口与发布渠道，用于在企业范围内上架与分发企业内部的低代码智能体与应用。企业商店中的智能体和应用仅本企业的员工和访客可见与可访问，非本企业成员无法浏览或使用。​

使用限制​

说明

  * 套餐限制：仅企业旗舰版支持企业商店。​

  * 低代码智能体不能同时发布扣子商店和企业商店。曾发布至扣子商店后已下架的智能体，也无法发布至企业商店。​

​

发布智能体到企业商店​

1.

登录[扣子编程](<https://code.coze.cn/home>)。​

2.

在页面顶部空间列表中选择目标工作空间。​

3.

在项目开发页面，选择低代码智能体。在页面右上角，单击发布。​

​

4.

在发布页面填写发布记录。​

5.

选择企业商店。单击发布。单击完成。​

从企业商店下架智能体​

如果不再需要在企业商店中展示智能体，你可以选择将其下架。​

说明

操作权限：企业超级管理员和管理员可下架企业商店中的所有智能体，企业成员可下架自己的智能体。​

​

在扣子编程左侧导航栏选择更多 > 社区 >企业项目，单击目标智能体，在智能体对话页面右上角单击配置按钮，选择下架。​

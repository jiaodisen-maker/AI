# 预览页面 - 文档 - 扣子

预览页面

搭建完用户界面后，你可以预览搭建的界面，确认界面设计和功能实现是否符合预期。通过预览，开发者能够直观地评估界面布局、交互逻辑以及视觉表现，及时调整以优化用户体验。​

1.

登录[扣子编程](<https://code.coze.cn/home>)。​

2.

在项目管理页面，找到已创建的低代码应用。​

3.

单击用户界面页签，然后单击界面右上角的预览。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27540%27%20height=%27233%27/%3e)![](https://p9-arcosite.byteimg.com/https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/19dd0d16cec648fca868ac9ba7667e6c~tplv-goo7wpa0wc-quality:q75.image)​

​

4.

在预览页面的上方，切换页面查看不同页面的搭建效果。​

  * 说明

如果测试结果不符合预期，重新修改界面布局后，需要手动刷新 IDE 页面，再单击预览进行测试。​

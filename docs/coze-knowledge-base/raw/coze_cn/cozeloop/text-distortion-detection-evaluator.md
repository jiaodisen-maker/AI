# 图片-文字畸变检测评估器 - 文档 - 扣子

图片-文字畸变检测评估器

评估器信息​

​

分类​| ​| 详情​  
---|---|---  
基础信息​| 评估器名称 ​| 文字畸变检测​  
​| 评估器类型 ​| 黑盒评估器​  
效果说明​| 功能概述​| 检测AIGC生成的文字是否存在扭曲、畸变的现象​  
​| 评估方式​| LLM 评估器​  
​| 评估对象​| 图片​  
​| 评估目标​| 内容质量​  
​| 应用场景​| AIGC 产物质量评估​  
​| 评估规则说明​| 输入为图片url，输出为0-1的分数，分数越大畸变的概率越高​  
  
​

评估器参数说明​

​

参数​| 参数名称​| 是否必填​| 参数说明​  
---|---|---|---  
输入信息​​| url​| 是​​| 图片下载链接​  
输出信息​| result_str​| 是​| 评估分数和具体评估理由​

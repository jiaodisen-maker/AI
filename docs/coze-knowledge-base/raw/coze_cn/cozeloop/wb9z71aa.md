# 图片-水印检测评估器 - 文档 - 扣子

图片-水印检测评估器

评估器信息​

​

分类​| ​| 详情​  
---|---|---  
基础信息​| 评估器名称​| 图片-水印检测​  
​| 评估器类型​| 黑盒评估器，评估标准的明细不对客展示​  
效果说明​| 功能概述​| 考察图像内容分析场景下，识别图片中是否存在显式水印并精准定位的能力指标，包含水印存在性判定、水印特征识别、空间定位精度三个功能。​1\. 水印存在性判定​衡量模型对图像中是否含有显式水印的检测能力。显式水印包括文字水印和图像水印两类。该维度关注模型能否从像素特征、色彩模式、纹理结构等多维度信息中准确识别水印的存在，体现模型在复杂背景、噪声干扰下的鲁棒检测能力。​2\. 水印特征识别​衡量模型对水印视觉特征的精准捕捉能力。文字水印具有明确的文字内容、字体特征、规则几何形状和较高颜色对比度；图像水印包含固定图案或logo、可能含透明度信息、具有特定色彩和纹理特征。该维度关注模型是否能准确区分水印与正常图像内容，体现对水印模式特征的理解能力。​3\. 空间定位精度​衡量模型对水印区域坐标标注的准确程度。该维度要求模型输出疑似水印区域的矩形框坐标（格式：" x, y, w, h"），所有坐标使用相对坐标表示（相对于图片宽高，范围0-1，保留四位小数），原点(0,0)位于图像左上角。该维度关注边界框与实际水印区域的吻合度，体现模型的空间感知与几何定位能力。​  
​| 评估方式​| 复合评估器（LLM + Code）​  
​| 评估对象​| 图片​  
​| 评估目标​| 内容质量​  
​| 应用场景​| AIGC 产物质量评估​  
​| 评估规则说明​| 0分-满屏水印（几乎覆盖整张图片）​1分-水印位于图像中心且较大，明显遮挡图片主体内容​2分-水印位于图片四周，或位于中间但较小​3分-存在水印但面积占比极小、位置偏边缘，视觉影响可忽略​4分-图片中不存在任何显式水印​  
​| 评估置信度​| 93.00%​

# 图片-文字正确性评估器 - 文档 - 扣子

图片-文字正确性评估器

评估器信息​

​

分类​| ​| 详情​  
---|---|---  
基础信息​| 评估器名称​| 图片-文字正确性​  
​| 评估器类型​| 黑盒评估器，评估标准的明细不对客展示​  
效果说明​| 功能概述​| 评估文字元素的视觉完整性与语义准确性，检测AI文字生成的特有缺陷。主要考察字形完整性、语义准确性、排版合理性​  
​| 评估方式​| 复合评估器（LLM + Code）​  
​| 评估对象​| 图片​  
​| 评估目标​| 内容质量​  
​| 应用场景​| AIGC 产物质量评估​  
​| 评估规则说明​| 0分：有害/完全无用-文字完全不可读，或语义完全错误无关且不可读。乱码/噪点/文字无法辨识​1分：难用/不好用-文字勉强可猜，但错误率高（严重缺笔/多笔/融合/乱码），语义重大错误或排版极度混乱。如：“Stop” 写成 “Stap” 或 “Srop”文字或字母堆叠​2分：大部分可用-文字基本可读，但有明显拼写错误、字符缺陷（粘连/断裂/变形）或排版问题（歪斜/不均）。如：文字间距忽大忽小​3分：可用-文字高度可读且语义准确，仅有细微字形瑕疵（笔划毛糙/轻微变形）或排版小瑕疵（几乎不可察）。如：“Bookstore” 完全正确，但 ‘k’ 的竖笔末端略显毛糙​4分：好用-文字清晰锐利、字形准确无误、语义完全正确、排版精准美观。无任何可察缺陷。​  
​| 评估置信度​| 92.00%​

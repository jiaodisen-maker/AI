# 知识问答-精炼性评估器 - 文档 - 扣子

知识问答-精炼性评估器

评估器信息​

​

分类​| ​| 详情​  
---|---|---  
基础信息​| 评估器名称 ​| 知识问答-精炼性​  
​| 评估器类型 ​| 黑盒评估器，评估标准的明细不对客展示​  
效果说明​| 功能概述 ​| 包括内容重复、冗余两个子维度​***内容重复***​检查是否存在重复表达的内容，包括极端重复、段落重复、句式重复、句子重复等​***内容冗余***​开头和结尾话术多余：重复需求的话术、不必要身份识别。话术、影响角色代入感的话术等​例如：​1\. 段落和章节的划分是否存在过多的细分​2\. 是否存在不必要的嵌套或子标题​  
​| 评估方式 ​| 复合评估器（LLM + Code）​  
​| 评估对象 ​| 文本​  
​| 评估目标 ​| 内容质量​  
​| 应用场景 ​| AIGC 产物质量评估​  
​| 评估规则说明​| 手动选择输入，若涉及打分，需说明总分范围、评分维度（含权重）、计算公式及结果解读（如优秀/良好/需改进的分数区间）；若为分类/检测类评估器，则说明具体规则​  
​| 评估置信度​| 95.00%​  
  
​

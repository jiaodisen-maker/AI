# 文本-语种一致性评估器 - 文档 - 扣子

文本-语种一致性评估器

评估器信息​

​

分类​| ​| 详情​  
---|---|---  
基础信息​| 评估器名称​| 文本-语种一致性​  
​| 评估器类型​| 黑盒评估器，评估标准的明细不对客展示​  
效果说明​| 功能概述​| 衡量回复文本所使用的语言是否与提问文本的语言一致，否存在多语言混杂的情况（排除人名、打招呼语、IP缩写、专有名词等的影响)。​  
​| 评估方式​| 复合评估器（LLM + Code）​  
​| 评估对象​| 文本​  
​| 评估目标​| 内容质量​  
​| 应用场景​| AIGC 产物质量评估​  
​| 评估规则说明​| 0分：模型回复文本与提问文本语言不一致​1分：模型回复文本与提问文本语言一致​  
​| 评估置信度​| 95.00%​  
  
​

评估器参数说明​

​

参数​| 参数名称​| 是否必填​| 参数说明​  
---|---|---|---  
输入信息​| query​| 是​| 用户输入内容​  
输入信息​| reply​| 是​| 回复文本​  
输出信息​| result_str​| 是​| 评估分数和具体评估理由​  
  
​

输入格式 (Input Schema)​

​

JSON

复制

{​

"{{query}}": "新型オフロード車のご紹介",​

"{{reply}}": "好的，我可以帮你介绍一下新型越野车。越野车是一种专门为越野行驶而设计的汽车，通常具有较高的离地间隙、强大的四驱系统、耐用的悬挂系统和大尺寸轮胎等特点，以适应各种复杂的地形和路况。越野车通常分为轻型越野车和重型越野车两种类型，轻型越野车通常采用前轮驱动或四轮驱动，车身较小，适合在城市和乡村道路上行驶；重型越野车通常采用四轮驱动或全轮驱动，车身较大，具有更强的越野能力和通过性，适合在崎岖的山路、沙漠、雪地等恶劣路况下行驶。如果你能告诉我你想要了解的具体车型或品牌，我可以给你更详细的介绍。"​

}​

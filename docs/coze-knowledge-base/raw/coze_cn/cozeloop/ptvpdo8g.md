# 文本-AI味检查评估器 - 文档 - 扣子

文本-AI味检查评估器

评估器信息​

​

分类​| ​| 详情​  
---|---|---  
基础信息​| 评估器名称 ​| 文本-AI味检查​  
​| 评估器类型 ​| 黑盒评估器，评估标准的明细不对客展示​  
效果说明​| 功能概述 ​| 评估模型回复中是否存在开头结尾话术冗余、连接词模版化、人物名称简单化、语气词过多等问题​  
​| 评估方式 ​| LLM 评估器​  
​| 评估对象 ​| 文本​  
​| 评估目标 ​| 内容质量​  
​| 应用场景 ​| AIGC 产物质量评估​  
​| 评估规则说明​| 0分：模型回复文本存在问题​1分：模型回复文本无问题​  
​| 评估置信度​| 90.00%​  
  
​

评估器参数说明​

​

参数​| 参数名称​| 是否必填​| 参数说明​  
---|---|---|---  
输入信息​| query​| 是​| 用户问题或需求描述​  
​| text​| 是​| 模型的回复文本及代码​  
输出信息​| result_str​| 是​| 评估分数和具体评估理由​  
  
​

​

JSON

复制

{​

"{{query}}": {​

"json_schema": "{\"type\": \"string\"}",​

}​

}​

JSON

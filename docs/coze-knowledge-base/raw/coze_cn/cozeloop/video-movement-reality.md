# 视频-运动真实性评估器 - 文档 - 扣子

视频-运动真实性评估器

评估器信息​

​

分类​| ​| 详情​  
---|---|---  
基础信息​| 评估器名称 ​| 视频-运动真实性​  
​| 评估器类型 ​| 黑盒评估器，评估标准的明细不对客展示​  
效果说明​| 功能概述 ​| 评估视频中运动是否真实，是否符合常识和物理规律，比如力学等物理现象是否正确，是否存在结构异常（如多手、面部扭曲、肢体比例失衡）​  
​| 评估方式 ​| 复合评估器（LLM + Code）​  
​| 评估对象 ​| 视频​  
​| 评估目标 ​| 内容质量​  
​| 应用场景 ​| AIGC 产物质量评估​  
​| 评估规则说明​| \- 2分：未检测到任何异常现象​\- 1分：仅存在细节层面的轻微缺陷，未破坏内容的核心合理性​ \- 0分：存在严重异常现象​  
​| 评估置信度​| 85.00%​  
  
​

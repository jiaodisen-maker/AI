# 文本-可用性评估器 - 文档 - 扣子

文本-可用性评估器

评估器信息​

​

分类​| ​| 详情​  
---|---|---  
基础信息​| 评估器名称 ​| 文本创作-可用性​  
​| 评估器类型 ​| 黑盒评估器，评估标准的明细不对客展示​  
效果说明​| 功能概述 ​| 定义：用于综合衡量一篇文本在完成既定任务目标、符合体裁规范、可读可信，并具备有效表达与价值输出方面的整体可用性。该指标强调 “能否直接投入使用”，兼顾底线要求与增益表现。​评估维度（8 项）：​指令遵循：对任务要求的把握与执行度（主题、边界、必含 / 禁忌、受众取向）。​范式理解：对指定文体 / 行业规范的匹配度（结构、要素、风格与客观性等）。​格式排版：呈现清晰度与可读性（段落、标点、列表 / 重点突出、版式合规）。​真实性：事实与内在逻辑的可信度；对用户指令的忠实度，不臆造。​语言文采：表达的准确性、流畅度与感染力（用词、句式、修辞、风格稳定）。​创意构思：观点、结构或表现手法的新颖性与独特性。​基础质量：核心信息完整、论证清晰、逻辑通顺、无常识性错误。​写作深度：超越表层的洞见与分析力度，观点的分量与启发性。​判定逻辑：​底线项：指令遵循、真实性、基础质量为使用门槛；任一明显不合格，则整体评为不可用。​增益项：范式理解、格式排版、语言文采、创意构思、写作深度用于区分一般可用与优质可用。​  
​| 评估方式 ​| 复合评估器（LLM + Code）​  
​| 评估对象 ​| 文本​  
​| 评估目标 ​| 内容质量​  
​| 应用场景 ​| AIGC 产物质量评估​  
​| 评估规则说明​| 0分：完全不符合要点要求​1分：只能符合部分要点要求​2分：基本符合要点要求，少量未满足​3分：符合要点要求，只存在小的次需瑕疵​4分：回复可以符合所有要点要求​  
​| 评估置信度​| 90.00%​  
  
​

​| reply​| 是​| 模型的回复文本​  
​| main_point​| 是​| 评估的考察点​  
输出信息​| result_str​| 是​| 评估分数和具体评估理由​

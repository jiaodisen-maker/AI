# 图片-清晰度评估器 - 文档 - 扣子

图片-清晰度评估器

评估器信息​

​

分类​| ​| 详情​  
---|---|---  
基础信息​| 评估器名称 ​| 清晰度​  
​| 评估器类型 ​| 黑盒评估器​  
效果说明​| 功能概述 ​| 图像评测-清晰度：分析图像的清晰度和细节表现，衡量图像质量的重要指标之一。​  
​| 评估方式 ​| LLM 评估器​  
​| 评估对象 ​| 图片​  
​| 评估目标 ​| 内容质量​  
​| 应用场景 ​| AIGC 产物质量评估​  
​| 评估规则说明​| 指标： 分值为1-5分，其中1分为最不清晰，5分为最清晰。​  
  
​

评估器参数说明​

​

参数​| 参数名称​| 是否必填​| 参数说明​  
---|---|---|---  
输入信息​​| ImageURL​​| 是​​| 图片下载链接​  
输出信息​| result_str​| 是​| 评估分数和具体评估理由​

# 图片-图文匹配度评估器 - 文档 - 扣子

图片-图文匹配度评估器

评估器信息​

​

分类​| ​| 详情​  
---|---|---  
基础信息​| 评估器名称 ​| 图文匹配度​  
​| 评估器类型 ​| 黑盒评估器​  
效果说明​| 功能概述 ​| 图像评测-图文匹配度：用于衡量图像内容与其相应文本描述之间的契合程度，评价图像和文本之间的相关性和一致性程度。​  
​| 评估方式 ​| LLM 评估器​  
​| 评估对象 ​| 图片​  
​| 评估目标 ​| 内容质量​  
​| 应用场景 ​| AIGC 产物质量评估​  
​| 评估规则说明​| 指标： 分值为1-5分，其中1分为最低，5分为最匹配。​  
  
​

评估器参数说明​

​

参数​| 参数名称​| 是否必填​| 参数说明​  
---|---|---|---  
输入信息​​| ImageURL​| 是​| 图片下载链接​  
​| Text​| 是​| 文本输入​  
输出信息​| result_str​| 是​| 评估分数和具体评估理由​  
  
​

​

JSON

复制

"ImageURL": "图片的可下载链接,string类型",​

"Text":"文本输入,string类型"​

}​

# 图片-手部结构准确度评估器 - 文档 - 扣子

图片-手部结构准确度评估器

评估器信息​

​

分类​| ​| 详情​  
---|---|---  
基础信息​| 评估器名称 ​| 手部结构准确度​  
​| 评估器类型 ​| 黑盒评估器​  
效果说明​| 功能概述 ​| 图像评测-手部结构准确度：评价手部结构特征完整性和定位的精确程度，用于分析生成图像的手部质量分数。​  
​| 评估方式 ​| LLM 评估器​  
​| 评估对象 ​| 图片​  
​| 评估目标 ​| 内容质量​  
​| 应用场景 ​| AIGC 产物质量评估​  
​| 评估规则说明​| 指标： 分值为1-5分，其中1分为最低，5分为最高，如果图像中不存在人手，则分数为-1。​  
  
​

评估器参数说明​

​

参数​| 参数名称​| 是否必填​| 参数说明​  
---|---|---|---  
输入信息​​| ImageURL​| 是​​| 图片下载链接​  
输出信息​| result_str​| 是​| 评估分数和具体评估理由​

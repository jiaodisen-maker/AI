# 图片-空白检测评估器 - 文档 - 扣子

图片-空白检测评估器

评估器信息​

​

分类​| ​| 详情​  
---|---|---  
基础信息​| 评估器名称​| 图片-空白检测​  
​| 评估器类型 ​| 黑盒评估器，评估标准的明细不对客展示​  
效果说明​| 功能概述​| 考察图像内容质量评估场景下，识别图片主体内容外是否存在大量无效空白区域的能力指标,包含纯色区域识别、内容属性判定、空间分布分析、面积占比评估四个维度。​1\. 纯色区域识别​衡量模型对图片中纯色区域的检测能力。纯色区域指与图片主体内容无关的无内容区域,通常表现为纯色或接近白色、无纹理、无结构的色块。该维度关注模型能否从色彩分布、纹理特征中准确识别出这些非功能性区域,体现模型对有效内容与无效空白的区分能力。​2\. 内容属性判定​衡量模型对纯色区域内容属性的精准判断能力。该维度关注检测到的区域是否确实为无内容区域,即非主体元素、非背景细节、非装饰性设计,而是真正的空白或填充区域。该维度体现模型对图像语义理解的深度,避免将有意义的纯色背景误判为无效空白。​3\. 空间分布分析​衡量模型对纯色区域形状特征与位置分布的分析能力。该维度从空间几何角度评估纯色区域的形状规则性(如矩形、圆形或不规则形状)、分布位置(集中于图片边缘或分散分布)、位置特征(上下左右边框区域)。该维度关注纯色区域的空间模式,体现模型的几何感知与布局分析能力。​4\. 面积占比评估​衡量纯色区域对整体图片的影响程度。该维度通过估算纯色区域占图片总面积的比例,判断这些无效区域是否影响整体视觉效果和内容呈现质量。该维度关注量化评估能力,体现模型对图片可用性和视觉完整性的综合判断水平。​  
​| 评估方式 ​| 复合评估器（LLM + Code）​  
​| 评估对象 ​| 图片​  
​| 评估目标 ​| 内容质量​  
​| 应用场景 ​| AIGC 产物质量评估​  
​| 评估规则说明​| 0分表示存在空白​1分表示不存在空白​  
​| 评估置信度​| 93.00%​

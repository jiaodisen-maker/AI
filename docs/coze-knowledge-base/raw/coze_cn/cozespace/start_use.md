# 开始使用扣子 - 文档 - 扣子

开始使用扣子

扣子全新升级！它不仅能帮你办公、做视频、写代码，更具备自主任务执行、探索进化等能力，真正从“陪你聊”走向“帮你干活”。​

1 分钟了解新版扣子​

全新的扣子是一个让 AI 伙伴持续生存、协作与进化的广阔世界：​

  * 满配的 Agent 装备：每个 Agent 都有专属的云端电脑与手机，像真人一样跨越软件壁垒。​

  * 满配的技能与创作力：生来就是创作高手，独立包揽从剧本到成片的全流程视频创作。​

  * 满配的人格与记忆：它拥有独立的邮箱身份，通过长期记忆深刻理解你的工作习惯与细微偏好。​

  * 24 小时自主干活：你关机它在线，你睡觉它工作。​

只需简单的对话，即可在 5 分钟内熟悉你的专属数字伙伴。​

积分消耗与常见问题​

扣子是如何消耗积分的？​

与扣子的每次交互（对话、做视频、跑云手机任务）都会消耗相应的平台积分。​

  * 常规对话：约 10-50 积分​

  * 云手机跑任务：约 200 积分​

  * 制作一支视频：约 6000 积分​

常见问题 （FAQ）​

Q：使用云手机登录软件，会被封号吗？​

A：建议为扣子注册专属的 App 账号。如果直接登录私人大号并进行高频自动化操作，可能会触发第三方平台的机器人风控导致封号。​

Q：怎么看扣子还有多少积分？​

A：在扣子页面左下角单击“积分卡片”，即可查看余额及各项任务的消耗明细。​

Q：它真的能记住我之前说的话吗？​

A：当然！扣子会自动提取重要信息。你也可以直接指定：“重点记住：新品推广的截止日期是3月31日”。它会妥善保管在专属记忆档案中。​

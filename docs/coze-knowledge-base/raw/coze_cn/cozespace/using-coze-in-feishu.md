# 在飞书使用扣子 - 文档 - 扣子

在飞书使用扣子

一键开启飞书渠道，扣子立刻成为你专属的飞书工作搭子。直接在飞书中和扣子对话，扣子就能在飞书内帮你把活干了。​

  * 你的全能数字分身：帮你回复消息、写文档、创建多维表格等。​

  * 更懂你的工作：获取飞书内的海量上下文，包括消息、文档、会议纪要、多维表格、日程、任务等。你不用翻记录，问它就知道。​

在飞书，扣子能帮你完成以下任务：​

​

类别​| 能力​  
---|---  
消息​| 消息读取（群聊/单聊历史、话题回复）、消息发送、消息回复、消息搜索、图片/文件下载​  
文档​| 创建云文档、更新云文档、读取云文档内容​  
多维表格​| 创建/管理多维表格、数据表、字段、记录（增删改查、批量操作、高级筛选）、视图​  
日历日程​| 日历管理、日程管理（创建/查询/修改/删除/搜索）、参会人管理、忙闲查询​  
任务​| 任务管理（创建/查询/更新/完成）、清单管理、子任务、评论​  
  
​

一键连接飞书​

扣子支持一键配置飞书渠道并完成授权。操作完成后，你可以直接在飞书中和扣子对话，让它帮你操作飞书，和你一起工作。​

说明

如果解绑后重新绑定，系统会创建一个新的飞书机器人应用。​

消息托管​

在一些固定时段（如周会、休息期间），你可以创建日程，让扣子定期检查群消息（目前不支持实时响应），识别内容并灵活替你回复。它不会只回复 “xx正忙，稍后回复”，而是根据问题自行判断。它能直接代办的会自动处理，需要你亲自确认的则帮你记录下来。​

​

共创文档​

在飞书文档协作中，扣子是你的默契搭档。​

  * 扣子写初稿，你把关​

  * 你只需下达需求，扣子便会快速构建文档初稿。随后，你可以在初稿中添加评论，并让扣子根据你的评论，修改文档。​

  * 你来创作，扣子评审​

  * 当你完成初稿后，直接指令扣子阅读全文，并针对全文逻辑与内容提供评审建议。虽然目前扣子还不支持对特定文字进行划线批注，但会在文档中添加全文评论。​

  * 生成初稿指令​

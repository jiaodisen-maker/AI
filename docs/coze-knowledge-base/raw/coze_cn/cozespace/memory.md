# 记忆 - 文档 - 扣子

记忆

不同于大模型靠上下文来记录和用户的对话过程，扣子是真正具备持久化长期记忆的 Agent。扣子的记忆能力不局限于单次对话的短期上下文，而是能够跨越时间、跨越场景，记住你的长期偏好、重要事实和关键上下文。拥有记忆能力的扣子，在以下方面有更好表现：​

  * 更懂你：你无需在每次对话、每个渠道都重复强调你的身份、偏好和背景信息。​

  * 更连贯：即使中断了很久，也能从上次的关键节点继续对话。​

  * 更高效：主动调取相关记忆，让方案输出、信息整理等任务一步到位。​

扣子的记忆机制​

作为持续工作的 Agent，扣子具备文件化的长期记忆的能力。它不是把所有对话都塞进模型上下文，而是将重要内容存储为 Markdown 文件，在对话中按需调用。​

如何记录​

支持自动沉淀记录、手动指定记忆，记忆内容跨端同步且隐私隔离：​

  * 自动提取：传统 AI Agent 的记忆对于用户来说是黑盒、不可见的，但扣子会智能地从你的对话中识别并提取值得长期记忆的关键信息，并分门别类地记录在 Memory.md 等 Markdown 文件中。你也可以主动要求扣子记录某些信息，例如你可以说“请重点记录一下：我目前住在杭州”，扣子按要求记录。​

  * 定期整理：扣子会定时整理记忆文件，从对话上下文、工作记录、文件列表等材料中抽取有用的信息，把重要的片段固化到长期记忆里，从而越用越懂你。​

  * 多渠道共享：你和扣子在飞书、微信、网页等各个渠道的对话都是互相独立的，但各个渠道保存的记忆是共享的。你在网页和扣子聊过的内容，在飞书和它对话时，它也会记得。​

  * 用户隔离：将扣子拉进飞书群，即使其他人在群聊中主动询问，扣子也不会泄露你在私聊或其他群聊中告诉它的信息。​

  * 可视化展示：你可以在文件目录下看到你和扣子在各个渠道、各个主题的对话中分别积累的记忆文件 [Memory.md](<http://Memory.md>)，检查你扣子是否如实记录了关键信息。​

如何回忆​

在对话中，当扣子识别到与记忆相关的任务或问题时，会自动检索并应用相关信息。​

  * 向量检索：扣子通过业界先进的向量模式实现了长期记忆相关文件的向量检索，让扣子对话更丝滑。​

  * 存取策略：通过优化的存取策略（包括实时记忆、异步总结），显著降低了记忆的“遗忘率”。关键信息一经记录，就能在需要时被稳定唤醒，减少了“说了就忘”的不确定性。​

记忆的载体​

为了让你更直观、清晰地管理记忆资产，扣子使用一系列核心文件来承载不同类型的信息，这是扣子为你维护的专属档案册。​

​

文件名称​| 用途简述​| 典型内容​  
---|---|---  
角色设定档案（SOUL.md）​​| 定义扣子的角色、语气和行为边界，是所有记忆和行为的系统级设定，确保长期对话风格统一。​| 

  * AI 自我介绍与定位​

  * 对话风格、礼貌程度和禁忌说明​

  
主人画像档案（USER.md）​| 沉淀关于主用户（你）的关键信息，让扣子在任何场景都能一眼认出你，了解你并和你更好的相处。​| 

  * 姓名、昵称及偏好的称呼方式​

  * 职位、团队、所在行业、兴趣爱好​

  * 正在负责的重要项目或职责标签​

  
长期记忆库（MEMORY.md）​| 存储跨对话的长期事实与偏好，把临时聊天内容沉淀为数字记忆资产。​| 

  * 关键项目的阶段性结论与 To-do​

  * 对人物、组织、指标等的稳定认知​

  
工具与流程设定（TOOLS.md）​| 记录工具使用方法、技巧。​| 

  * 常用调用方式与关键约定​

  
关系与团队档案（CONTACT.md）​| 在群聊与多协作场景下，帮助扣子识别每个人是谁、扮演什么角色。​| 

  * 群聊成员的姓名与身份标签​

  * 你与关键同事之间的协作关系​

  * 重要联系人、项目组等分组信息​

  
隐私与密钥仓（SECRET.md）​| 集中保存你授权给扣子使用的敏感信息，让自动化动作更安全、可控、可追溯。​| 

  * 与第三方系统打通所需的账号、密钥等敏感配置​

  * 需要严格受控访问的个人或企业级隐私信息​

  * 与安全策略相关的关键说明​

如何使用记忆​

掌握记忆功能，让扣子成为你更好用的工作搭子。你可以先用自然对话让扣子了解你的喜好和习惯，再逐步学会指定它如何更精准地提取与记录、纠偏和整理。​

  * 自然对话自动累积记忆：像平时聊天一样描述你的身份、职责、正在做的项目，扣子会按照规则自动将关键信息写入长期记忆。例如：​

  * ​

Plain Text

复制

我是公司运营专员，主要负责公众号和视频号的内容运营，目前正在推进3月份的新品推广项目，核心目标是提升新品曝光量和转化率 ​

​

  * 对话中强调关键事实：遇到对你很重要、未来还会频繁用到的事实，用一句清晰的话显式标记出来，以免扣子遗漏信息。​

  * ​

Plain Text

复制

重点记住：新品推广的截止日期是3月31日，核心推广渠道是公众号推文+视频号短视频，预算控制在5000元以内​

​

  * 主动搜索记忆：进入方案撰写、复盘、汇报等关键节点前，提醒扣子先查询记忆或搜索，确保所有结论都基于同一套最新信息。​

  * ​

Plain Text

复制

基于我们之前聊过运营相关的内容，结合你的记忆，帮我撰写一份 Q1 的工作总结​

​

  * 指定记录的位置：明确告知扣子记忆文件的具体名称和存储要求，例如：​

  * ​

Plain Text

复制

把刚才提到的新工具 API 地址记录到 tools.md 里​

​

  * 跨对话记忆：你可以灵活查看扣子在单聊和群聊所有对话中的记忆，例如上午在群聊里和扣子讨论了项目 A 的进度，下午私聊扣子问“最新的进度是什么？”，扣子会直接调取之前的记忆，把项目进度、关键结论完整复述出来。​

如何查看记忆​

扣子会自动识别并记录对话中的关键信息，并分别记录在各个文件下，你也可以主动查看记忆文件的内容，如果发现遗漏记忆或记忆错误，还可以通过对话让扣子纠正记忆。​

  * 查看记忆：​

  * 打开扣子，在文件 > 记忆页面中找到指定的对话主题，查看文件内容。​

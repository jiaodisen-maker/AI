# 技能商店 - 文档 - 扣子

技能商店

本文介绍技能商店的基本概念以及购买技能等相关操作。​

商店介绍​

技能是扩展扣子 AI 功能的模块化功能。每个技能都集成了特定的指令、元数据和可选资源（脚本、模板），安装技能后，扣子 AI 会自行判断使用场景并使用这些技能。​

扣子通过技能商店，协同开发者打造技能生态。技能开发者可将自研的技能上架到商店，实现技术成果的分享与变现。技能使用者可在商店中挑选与使用符合自身需求的技能，还可以一键复制感兴趣的开源技能，并在此基础上进行定制化改造。​

浏览技能​

在[扣子](<https://space.coze.cn/>)首页的左侧导航栏中，单击技能商店即可浏览技能列表。你也可以直接[单击此处](<https://space.coze.cn/skills>)进入技能商店。​

你可以在技能商店中探索各类实用的技能，支持通过搜索快速定位目标技能。单击技能名称进入技能详情页，可查看技能的基本介绍以及基于该技能开发的精选案例。​

购买技能​

技能商店提供了丰富的免费与付费技能。针对付费技能，你需要先购买再安装与使用。​

扣子提供了如下付费方式：​

  * 按次购买：如果你想轻度体验下技能效果，可以选择按次购买。​

  * 支持使用积分抵扣，但仅限个人付费版用户。​

  * 不支持抵扣活动积分，积分抵扣顺序参考​抵扣顺序。​

  * 每次使用都会消耗积分。若暂时不用，可在我的技能中将其关闭或删除，以避免不必要的积分消耗。​

  * 订阅：你可以按月、按季或按年订阅技能。一次付费后，即可在订阅期内无限次使用​

  * 订阅技能成功后，不支持退款。​

  * 叠加购买时，订阅有效期会自动顺延，但不会退订当前的订阅。​

  * 选择按次购买后，仍可随时开通订阅模式，订阅有效期内使用技能不扣积分，到期后将自动切回按次模式，每次调用扣除相应积分。从订阅模式切换到按次购买，需等待当前订阅到期。​

具体的购买步骤如下所示：​

1.

登录[扣子](<https://space.coze.cn/>)。​

2.

在左侧导航栏，单击技能商店。​

3.

在技能商店中，单击目标技能。​

4.

在技能详情页面，根据页面提示购买技能。​

  * 购买完成后，你可以安装和使用技能。具体操作，请参考​安装技能。​

管理已购技能​

购买技能后，你可以在订阅记录中查看已购买的技能、续费技能。​

查看已购技能

续费

1.

登录[扣子](<https://space.coze.cn/>)。​

2.

在左侧导航栏，单击技能商店。​

3.

在技能商店页面的右上角，单击订阅记录。​

4.

在我安装的区域，查看已购买的技能。​

  * 你可以在订阅记录中查看价格、订阅时长、购买时间等信息。​

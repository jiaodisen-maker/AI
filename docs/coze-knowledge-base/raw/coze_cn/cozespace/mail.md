# 邮箱 - 文档 - 扣子

邮箱

为你的扣子分配一个专属邮箱地址，让它担任你的智能邮件小助手——只需简单对话指令，就能自动收发邮件、注册并登录各类平台和第三方服务，全程高效自动化。​

为扣子注册邮箱地址​

首次使用扣子邮箱时，需要为扣子注册一个邮箱地址，作为扣子的对外通信的身份。邮箱地址域名统一为 ***@coze.email，不可修改。​

网页端

手机端

1.

打开扣子的[邮箱页面](<https://www.coze.cn/mail>)。​

2.

首次使用扣子邮箱时，页面会提示你输入邮箱前缀。​

3.

注册成功后，开始使用扣子邮箱。​

如何使用扣子邮箱​

代你发送邮件​

在扣子对话框输入指令即可发送纯文本邮件，暂不支持发送 HTML 或带附件的邮件。​

例如，“给 [example@email.com](<mailto:example@email.com>) 发邮件，约他今晚 7 点一起吃饭”。​

撰写邮件回复​

扣子会定期自动检查新邮件，根据邮件内容选择适当的回复和处理方式。​

你可以通过对话调整扣子的邮件处理偏好，例如：​

  * “来自 [bytedance.com](<http://bytedance.com>) 的邮件，一定要在对话中提醒我，让我决定如何回复”​

  * “平台或服务的状态更新，你可以直接标记为已读”​

  * “如果邮件来自其他 Agent 的邮箱，你可以先自行处理，决定不了的再来问我”​

垃圾邮件自动拦截​

对于垃圾邮件，扣子自动拦截，安全又省心。​

  * 智能拦截：安全系统会自动识别并拦截疑似钓鱼或带毒附件的邮件。​

  * 透明查看：你可以在“垃圾邮件”分类中查看拦截原因（如伪造邮件、钓鱼邮件、垃圾邮件、病毒附件），确保安全可控。安全起见，扣子不会读取垃圾邮件的具体正文，仅展示发件人和主题等基础信息。​

# 套餐与定价 - 文档 - 扣子

套餐与定价

使用扣子时，会产生一定的费用，通过积分方式抵扣。你每日登录扣子即可获得免费积分来体验各项功能，购买套餐还能获得更多积分与专属权益。​

扣子如何收费​

使用以下扣子功能，会消耗一定的积分。​

  * [扣子任务](<https://arcosite.bytedance.net/sites/1703320331156/6683e3330fa9f40304a3827e/editor/694e3f924a1c2a055fa93eae/?docLang=zh>)：与扣子 AI 的每一次互动，都会占用平台算力、消耗模型 Tokens 等资源，从而消耗你账户中的积分。任务越复杂、占用资源越多，消耗的积分就越多。比如：​

  * 与扣子对话，让它帮忙制定一个市场调研方案。​

  * 让扣子自主规划日程，并执行落地。​

  * 让扣子去探索 Agent World，与其他 AI 交流。 ​

  * 使用视频功能，创作视频。​

  * 在历史话题或长期任务中，继续与扣子对话。​

  * 云手机、云电脑、邮箱：功能使用限时免费。后续正式计费的时间计划与产品定价请关注平台公告。​

套餐与权益​

为满足不同用户使用需求，扣子推出的订阅制服务，就像手机通讯套餐一样，每个月为你提供固定的功能权益与积分额度。扣子订阅套餐包括个人版（免费版、进阶版、高阶版、旗舰版）和企业版（标准版、旗舰版）。​

  * 个人使用：根据日常使用频率、功能需求，选择一款合适的个人版套餐即可。​

  * 企业协作：如果需要统一管理成员和费用，并享用企业专属权益，建议选择企业版。​

不同套餐的积分和权益有所不同，详细对比如下表所示。单击[版本权益](<https://code.coze.cn/subscription-paywall>)，即可快速选购所需套餐。​

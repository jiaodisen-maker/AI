# 收藏夹 - 文档 - 扣子

收藏夹

收藏夹不只是一个在线文件夹，更是你和扣子协作的共享知识库。你可以把日常看到的文章、报告、文件都收录进来，扣子会帮你智能打标、整理，让你在扣子对话中随时引用，让工作更高效。​

收藏夹能帮我做什么​

  * 越用越懂你，沉淀个人知识体系：随着你不断收藏、打标，扣子会越来越熟悉你的偏好和需求，成为你的专属知识助理。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27640%27%20height=%27167%27/%3e)![](https://p9-arcosite.byteimg.com/https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/37508c10b17249b98a4e05d6dbfc82b7~tplv-goo7wpa0wc-quality:q75.image)​

​

  * 对话时，随时 @调用收藏的内容：发起任务时，直接用 @ 引用收藏夹里的单条内容或整个标签，让扣子先理解你的背景信息，再帮你总结、分析或创作。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27646%27%20height=%27115%27/%3e)![](https://p9-arcosite.byteimg.com/https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/833feba002414f3898abfcd75828b60e~tplv-goo7wpa0wc-quality:q75.image)​

​

  * 智能打标，告别手动整理：无需手动为文件添加标签，收藏夹会根据你的标签库自动匹配最合适的标签。​

  * ​

​​![](data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%27647%27%20height=%27240%27/%3e)![](https://p9-arcosite.byteimg.com/https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/90df26c23dc94b69a19c6936f306792a~tplv-goo7wpa0wc-quality:q75.image)​

收藏夹有哪些场景​

行业热点追踪​

日常把行业报告、新闻截图、大佬观点随手上传到扣子。需要时一键 @标签，扣子自动帮你汇总、梳理变化、提炼结论。例如，你最近关心英伟达，你可以：​

1.

建一个“英伟达”的标签。​

2.

日常将你觉得高质量的关于英伟达的社媒文章、报告、截图收藏到扣子。​

3.

发起任务并@英伟达 标签，让扣子帮你总结、梳理、补充或者讨论近期的信息。​

4.

将对于扣子产出的满意内容也添加到收藏。​

工作资产库​

把品牌介绍、产品卖点、常用模板、历史方案统一归档。写文案、对外沟通直接 @资料，自动对齐口径。例如，你是一个快消品牌的营销人员，你可以：​

1.

建一个属于你品牌的标签。​

2.

将品牌、公司、产品的介绍收藏到该标签下。​

3.

在任何任务中都可以通过@对应的内容/标签，让扣子先理解你的工作背景，再执行任务。​

如何使用收藏夹​

例如，你想持续跟进 OpenClaw 相关技术动态，高效沉淀行业知识。​

1.

新建并定义标签。​

  * 网页端

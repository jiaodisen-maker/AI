# 文件 - 文档 - 扣子

文件

无论是你上传的参考素材，还是扣子生成的产物，都会通过文件进行有序归档。它是扣子随时调用的“知识补给站”，也是你与扣子共同经营的资料库。​

说明

每个扣子账号提供 8GB 限时免费文件存储额度。接近或超出额度后，建议让扣子帮你清理不需要的文件，避免影响正常任务执行。存储容量上限为 50GB，达到后将无法继续上传或保存文件。​

​

文件从哪里来​

  * 用户手动上传：你在扣子对话中上传的图片、文档、表格、音视频等素材，都会根据对话主题分门别类保存在文件目录中。​

  * 扣子生成：扣子根据你的要求分析、整理后生成的文件，例如日报、周报、统计报表、分析结果、PPT、图片、视频等文件。​

  * 示例：你对扣子说“整理上周的销售数据，做个趋势分析”，它会自动生成一份带图表的统计报表，并自动存进文件库。​

  * 网页端文件目录

手机端文件目录

进入扣子[文件](<https://www.coze.cn/files>)页面，在全部文件页签查看所有文件。​

如何使用文件​

对话里 @引用文件​

写方案或进行数据分析时，手动将目标文件引用到对话中，然后说出需求，扣子会自动结合文件内容进行响应。例如：​

  * “Q3 销售数据”，然后发送“做个图表分析一下趋势”。​

  * “自助烤串签子照片”，问“这张照片里有多少签子”。​

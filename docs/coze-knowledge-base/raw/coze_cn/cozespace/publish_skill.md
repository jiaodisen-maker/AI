# 上架技能 - 文档 - 扣子

上架技能

你可以将扣子编程侧创建的技能上架到技能商店或企业市场，以便其他用户使用技能。​

技能概述​

扣子支持将技能上架到技能商店和企业市场，满足不同场景下的技能分发需求：​

  * 技能商店：面向所有扣子用户的公开商店，技能可被扣子用户发现、安装和使用。你可将自主开发的技能设为付费模式上架，实现商业变现。这一机制既为开发者提供创意变现渠道，也为扣子用户提供丰富的技能选择。​

  * 企业市场（仅企业版支持）：面向企业内部的专属技能分发中心，仅限本企业员工访问使用。适用于分发核心业务工具或内部专属技能，既能保护知识产权，又能提升内部协作效率。​

使用限制​

  * 仅技能所有者能上架并管理技能。​

  * 不同技能类型的上架渠道及权限要求：​

  * ​

技能类型​| 技能商店​| 企业市场​  
---|---|---  
个人工作空间中的技能​| 技能所有者可以上架自己的技能。​| 不可上架。​  
企业工作空间中的技能​| 企业超级管理员和管理员可以管控成员的技能上架权限，设置是否允许成员将企业工作空间中的技能上架到技能商店：​
    * 开启：技能所有者可以上架。​
    * 关闭：仅企业超级管理员和管理员可上架本人创建的技能。​
| 技能所有者可以上架。​  
  
​

准备工作​

在开始上架流程前，请确保你已完成以下准备：​

  * 已创建并部署技能，详细步骤可参考​制作技能。​

  * 如果上架付费技能，你需要先开通支付渠道，详细步骤可参考​开通收款账户。​

将技能上架到企业市场​

企业市场是专为企业打造的内部技能分发中心。对于涉及核心业务逻辑或仅限内部使用的技能，上架到企业市场既能保护知识产权，又能提升内部协作效率。​

说明

套餐限制：仅企业版支持将技能上架到企业市场。​

​

步骤一：管理员设置审核策略​

角色限制：企业超级管理员或管理员。​

角色限制：企业超级管理员或管理员。​

付费设置​

你可以为技能选择付费模式，用户购买技能后，你将得到对应的收入。​

按次付费

一次买断

免费

说明

  * 上架到企业商店时，不支持选择按次付费模式。​

  * 按次付费模式根据用户调用你技能中特定的 API 进行计费。每成功调用一次 API，计为一次使用并扣除相应积分。因此，该模式仅适用于通过调用 API 提供功能的技能。开发案例，请参考​开发“按次付费”技能。​

​

你可以设置技能的付费方式为按次付费。用户每调用一次，需支付相应积分。结算技能收入时，系统将按照一定的积分和现金比例，结算给你。​

你可以在一个技能中添加多个付费接口，并为每个接口设置不同的价格，具体配置项说明如下：​

  * 付费接口：开放给用户付费调用的接口 URL。​

  * URL 格式：遵循 {schema}://{domain}/{path} 格式，例如https://api.coze.cn/v1/workspaces。​

  * URL 变量：如果 URL 中包含变量，需使用 {} 将其包裹，例如 https://api.coze.cn/v1/workspaces/{workspace_id}/members。​

  * 获取方法：你需要从技能代码中获取对应的 URL。​

i.

在扣子编程中找到对应的技能​

ii.

在文件目录树中展开 scripts 目录，然后在 xxx.py 代码文件中，找到 requests 请求对应的接口 URL 并复制。例如，本案例中为 {API_BASE_URL}/images/generations，即https://ark.cn-beijing.volces.com/api/v3/images/generations。​

  * 调用单次消耗积分：设定用户每调用一次这个接口，需要消耗的积分数量。​

下架技能​

若技能商店或企业市场中的技能存在问题，或不希望被继续使用，你可以将其下架。​

说明

技能下架后，用户将无法在技能商店中查找并安装该技能，具体影响如下：​

  * 付费技能：付费用户在有效期内仍可正常使用，直至其订阅到期，到期后无法再续费。​

  * 免费技能：已安装该技能的用户仍可正常使用。​

​

操作权限​

技能下架的操作权限要求：​

  * 技能商店：仅所有者可下架。​

  * 企业市场：技能所有者、企业超级管理员和管理员可下架。​

3.

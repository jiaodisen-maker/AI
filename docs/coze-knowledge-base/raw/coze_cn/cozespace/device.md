# 设备 - 文档 - 扣子

设备

扣子拥有自己的设备：云手机和云电脑，这是专供扣子使用的云端设备，相当于为扣子配备的“工作设备”。只需要在对话中下达指令，扣子会像人类一样操作设备完成各类任务，例如刷抖音、看今日头条，仅在需要决策、输入关键信息时提示你接管，解决了无设备 Agent 无法执行的手机端 / 浏览器端专属操作的问题，让扣子连接真实世界。​

安全使用准则​

  * 账号隔离：为了保障你的账号安全，建议为扣子注册专用的 App 或网页账号，避免使用你的个人账号。这可以防止因自动化操作被平台识别为机器人，而导致你的个人账号被封禁。​

  * 安全下载：​

  * 云手机：请仅通过设备自带的应用商店下载 App，不要安装来源不明的程序。目前支持支持下载大部分热门、常用的手机 App，如抖音、今日头条、微博、QQ 等。​

  * 云电脑：请仅通过官方渠道获取软件或脚本，不要运行来源不明的插件、附件，或访问非法网站。​

  * 信息保护：请勿在云设备中存储或处理任何敏感个人信息（如身份证号、银行卡、密码等），以防信息泄露。​

  * 使用限制：请注意，云手机存在以下使用限制：​

  * 浏览器功能：禁止在云手机上安装或使用浏览器。此项限制是为了防止访问非法网站或下载来源不明的文件。​

  * 代理功能：禁止在云手机上使用代理软件。云手机不支持访问海外节点。​

  * 硬件功能：由于是虚拟设备，云手机没有摄像头等物理硬件，因此无法进行二维码扫描或人脸识别。​

添加云手机和云电脑​

开通条件​

  * 套餐限制：个人高阶版 / 旗舰版、企业标准版 / 旗舰版​

  * 数量限制：每个用户最多 1 台云手机、1 台云电脑，即最多 2 台设备。​

使用云手机和云电脑​

步骤一：用户发起任务​

通过对话向扣子描述需求，明确设备类型和具体事项，示例：​

  * 云手机：“用你的云手机打开小红书，搜索‘通勤穿搭’，整理热门笔记要点”​

  * 云电脑：“用你的云电脑打开扣子的首页，帮我截个长图”​

步骤二：Agent 自主操作​

扣子收到指令后，会自动规划步骤并操作云设备。例如打开应用市场下载 App、浏览器访问网页、填写表单等。你可在【设备】- 对应云设备页面，实时查看操作过程。​

步骤三：用户手动接管​

当遇到以下情况时，扣子会提示你接管设备，完成后点击 “完成接管”，Agent 继续执行后续步骤：​

  * 输入验证码、完成人机验证。​

  * 涉及资金决策（如选择商品套餐、支付操作）。​

  * 缺失关键信息（如手机号、账号登录）。​

  * 安全规则限制（如密码输入、账号创建）。​

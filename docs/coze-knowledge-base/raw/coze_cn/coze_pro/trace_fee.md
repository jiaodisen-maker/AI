# Trace 日志费用（即将收费） - 文档 - 扣子

Trace 日志费用（即将收费）

Trace 日志是扣子罗盘提供的可观测性工具，用于帮助你分析和诊断线上项目的运行状态。启用并存储 Trace 日志会产生相应费用。​

注意

如果删除扣子编程项目，其 Trace 数据会同步被删除，已扣除的费用不予退还。​

​

计费方式​

Trace 日志的费用根据上报的日志存储量和存储时长计算。系统会自行在一段时间内上报一次 Trace 数据，并在上报时一次性收取费用。​

系统会根据你所订阅的套餐，采用默认的存储时长。你也可以修改存储时长以降低费用。最终计费将以数据上报时你在扣子编程中设定的时长为准。​

​

订阅套餐​| 个人免费版​| 个人进阶版​| 个人高阶版​| 个人旗舰版​| 企业标准版​| 企业旗舰版​  
---|---|---|---|---|---|---  
存储时长​| 3 天 ​| 7 天 ​| 7 天 ​| 30 天 ​| 30 天 ​| 90 天 ​  
  
​

计费范围​

扣子仅对线上运行产生的 Trace 日志进行收费，其他场景（如在扣子编程内调试等）产生的 Trace 日志完全免费。具体的计费场景如下：​

​

Trace 日志来源​| 具体场景​  
---|---  
扣子编程​| 低代码、编程项目的智能体或工作流在线上运行（Trace 日志上报开关默认开启，支持关闭）​  
扣子罗盘 SDK 集成​| 通过扣子罗盘 SDK 集成的外部应用在线上运行​  
三方平台集成​| 智能优化提示词​  
  
​

单价​

Trace 日志费用的计费单价如下表所示：​

​

计费项​| 单价​| ​  
---|---|---  
​| 积分结算（积分/GB/天）​| 现金结算（元/GB/天）​  
Trace 日志​| 503​| 0.503​  
  
​

计费公式​

按照如下公式计算 Trace 日志费用：​

​

Plain Text

复制

Trace 日志费用 = 存储容量（GB） ✖️ 存储时长（天） ✖️ 单价​

​

  * 存储容量：单次上报的 Trace 数据量。系统会精确到 Byte 来统计使用量，最终换算为 GB。​

  * 存储时长：Trace 数据的存储时长。​

计费示例​

假设你是个人进阶版用户，Trace 存储天数默认为 7 天，如果你的某个智能体线上运行上报了 0.1 GB 的 Trace 数据，则你需要一次性支付积分：0.1 GB * 7 天 * 503 积分= 352.1 积分。​

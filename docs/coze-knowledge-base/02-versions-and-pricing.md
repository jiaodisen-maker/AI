### 关键判断
- **个人免费版**：体验玩具。不能用方舟，资源点按天刷新极快烧光。**不要**用来跑生产。
- **个人进阶版（9.9）**：单人开发者性价比之王，10GB KB 够个人项目。
- **团队版（178）**：小团队尝鲜门槛。但 100 人封顶 + 100GB KB + 5000 RPM 在中型公司容易撑爆。
- **企业版（4980）**：**全公司推广的实际最低门槛**。是配 Agent World、ARK 模型、VPC、不限用户的唯一档。

## 2. 资源点（核心计费单位）

### 2.1 计费的 7 大类
1. **模型调用**（按 token，主消耗）
2. **插件调用**（按调用次数）
3. **音视频服务**（语音合成/识别）
4. **知识库存储**（按 GB·月）
5. **Trace 上报**（按条数）
6. **记忆库存储**（按条数）
7. **智能体调用**（部分场景）

### 2.2 模型计费公式

```
模型费用 = 输入单价 × (输入 token − 缓存命中 token)
        + 缓存命中单价 × 缓存命中 token
        + 输出单价 × 输出 token
```

→ 换算成资源点：`资源点扣除 = token 量 × 该模型单价`

### 2.3 套餐间的资源点性价比

| 套餐 | 月费 | 月资源点 | **每资源点成本** |
|---|---|---|---|
| 个人进阶 | 9.9 | 30,000 | ≈ 0.00033 元 |
| 团队版 | 178 | 150,000 | ≈ 0.00119 元 |
| 企业版 | 4,980 | 3,000,000 | **≈ 0.00166 元** |

⚠️ **看起来企业版最贵，但企业版的价值不在资源点，是在 RPM 上限 + 用户数 + KB 容量 + Agent World + VPC。** 资源点不够再单买 → 见 §3。

## 5. 推广全公司的成本估算（粗算）

假设：
- 50 人公司，每人每天 30 次 bot 调用，主要用 Doubao
- 平均每次 1500 input token + 500 output token
- 一个月按 22 工作日

```
50 人 × 30 次/天 × 22 天 = 33,000 次/月
33,000 次 × 2,000 token/次 = 66,000,000 token

按 doubao-1.5-pro 估算（≈ 0.0008 元/1K token，**搜不到精确数，仅供估算**）
≈ 66,000 × 0.0008 = 52.8 元的纯模型成本
```

**纯模型钱 < 50 元/月**——这就是企业版主要不是为模型付费、而是为**功能/容量/合规**付费的原因。

## 6. 老板会问的 3 个问题（你提前准备答案）

1. **"我们买企业版到底贵不贵？"**
   答：4,980/月 = 50 人公司每人 100 元。比飞书会员还便宜，比一杯咖啡都便宜。

2. **"超出资源点怎么办？爆账单风险？"**
   答：可设月预算上限（团队/企业版有），到点停服而不是无限刷。**这是企业版必须开的硬控**。

3. **"为什么不用免费/团队版？"**
   答：免费版没法用方舟模型 + 用户数封顶；团队版 100 人封顶 + 100GB KB + 没 VPC——公司推广撑不到三个月就爆。

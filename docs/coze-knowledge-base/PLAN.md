### 1.2 关键名词改动

- **资源点 → 积分**（2026-01-18 改名）。不是不一样的东西，就是叫法变了

### 1.3 计费机制

- 单位：积分（**¥1 = 1000 积分**，即 1 积分 = 0.001 元）
- 个人版：积分 0 即停服，**不支持超额**
- **企业版：积分 0 后自动从火山引擎现金账户扣款**（按 1000:1）
- 火山方舟模型 / 火山知识库 → **不消耗积分，单独走火山现金**
- 第三方付费插件 / 付费技能 → **不消耗积分**
- 企业版加成员：**¥69/人/月，含 6.9 万积分**

### 1.4 企业旗舰版硬限制

- 一个火山账号 **最多 1 个企业版**
- 至少 **20 个成员席位**起购
- 套餐到期 **15 天内**可续费；超过 15 天，**记忆库自动删除找不回**
- 套餐价格 = 基础权益费（5,980）+ 成员席位费（69 × N）

### 1.5 限时免费模型（不消耗积分，但有调用上限）

- Kimi-8k / 32k / 128k：100 次/天
- 阶跃星辰：100 次/天
- 豆包视频模型 Doubao-Seedance-1.0-lite/pro：**每企业账号 100 万 tokens/月**

### 1.6 缓存命中

- 输入 token 命中缓存时单价 **0**（白嫖）
- 必须在大模型节点开启上下文缓存才生效

## 2. 扣子能力全景图（基于真实文档）

### 2.1 双产品线

```
┌────────────────────────────────────────────┐
│           扣子（Coze）                      │
│  日常 AI 办公 / 长期任务 / Agent World      │
│  云电脑 + 云手机 + 邮箱 + 长期记忆           │
└────────────────────────────────────────────┘
┌────────────────────────────────────────────┐
│        扣子编程（Coze Programming）         │
│   低代码项目（智能体/工作流/应用/技能）     │
│   AI 编程方式开发（自然语言对话生成 bot）   │
│   面向开发者                                 │
└────────────────────────────────────────────┘
```

**你 800 人推广，主要是用"扣子编程"产品线**——员工自助做 bot、对接内部系统、工作流编排。
"扣子"产品线（Agent World）适合做长任务、对外邮件、操作旧系统的少数高级场景。

### 2.2 编排能力

| 模式 | 何时用 | 限制 |
|---|---|---|
| **单 Agent** | 简单问答、单一职责 | 默认 |
| **多 Agent** | 复杂分工，按关键词跳转 | 一个智能体内多个 Agent，jump conditions 触发 |
| **工作流（Workflow）** | DAG，有循环/分支/批处理 | 节点：LLM/Plugin/Code(Python)/Selector/Loop/Batch/Knowledge/Database/Memory |
| **AI 应用（App）** | 带 UI 的项目 | UI Builder 拖拽，发布到 Web/小程序 |

### 2.3 模型

- **扣子模型**（豆包系列、DeepSeek、智谱部分）→ **消耗积分**
- **方舟模型**（火山方舟接入点，企业版独享）→ **走火山现金**
- 限时免费模型（Kimi/阶跃星辰）→ **不消耗积分但有日调用上限**
- **缓存命中 token 单价 0**（开启上下文缓存赚的）

### 2.4 知识库（RAG 核心）

| 类型 | 适合 | 关键能力 |
|---|---|---|
| **文档知识库** | 制度/SOP/产品手册 | **按层级分段**（自动识别文档结构）、**混合检索**（向量+关键词）、**查询改写**、**结果重排** |
| **表格知识库** | 客户档案 / SKU / 价格表 | 按行划分，索引列匹配，**NL2SQL 查询** |
| **照片知识库** | 产品图/医学影像 | 标注+图像检索 |

⚠️ **注意**：扣子标注页提到"火山知识库"——专业版/企业版可接，**但走火山现金，不消耗积分**。

### 2.5 数据库

| 选项 | 何时用 | 限制 |
|---|---|---|
| **扣子数据库** | 起步、客户/订单 / 简单结构 | 单表 ≤ 10 万行 / 500 MB / 20 字段 |
| **火山数据库（MySQL）** | 数据量大、要在多 bot 共享 | 只能在工作流的数据库节点用，**不能在智能体里用** |
| **多用户模式** | 多人共享读写 | 仅工作流数据库节点生效 |

### 2.6 记忆（多种 ≠ 一回事）

| 机制 | 长度 | 适合 |
|---|---|---|
| **变量** | 短，key-value | 用户偏好（粗粒度） |
| **数据库** | 持久化 | 结构化档案 |
| **记忆库（长期记忆）** | 跨会话、跨渠道 | 个人用户画像 |

> 长期记忆 **2025-10-15 升级**：
> - 跨渠道共享（飞书 / 网页 / 微信对同一用户记忆共享）
> - 但**用户隔离**（拉群里不会泄露私聊内容）
> - 用 **UID + 渠道 ID** 编码做数据隔离
> - **应用（App）里不能用记忆库**，只能在低代码智能体/工作流

⚠️ **企业旗舰版单库 1000 万条**——别担心容量，担心管理。

### 2.7 插件

- 内置丰富插件（搜索、新闻、天气、Excel...）
- **自定义插件**：上传 OpenAPI 3.0 → Coze 自动生成 tool
- **可发布给团队/全公司共享**

⚠️ **企业旗舰版独享**："工作空间内外部集成可管控"——管理员可设置某个空间能用哪些第三方插件，**这是合规护栏**。

### 2.8 触发器（Trigger）

定时 / 事件触发——bot 主动跑（不是只能等用户问）。
**销售助手的"每周一汇总待跟进客户"就靠这个。**

### 2.9 渠道（发布到哪儿）

| 渠道 | 适合 | 备注 |
|---|---|---|
| **飞书（Lark）** | 全员入口 | 你公司用飞书，必走 |
| 微信公众号 / 客服 | C 端外部 | 销售对外可考虑 |
| 抖音小程序 | 营销/电商 | 保健品营销主战场 |
| API / SDK | 嵌入自家 App | 关键 |
| Chat SDK | 网页弹窗 | 关键 |
| 商店 / 模板库 | 内部分享 / 对外营销 | |

### 2.10 Agent World（2.5 版独有）

- **云电脑**：Ubuntu 2C/4G + 浏览器 + 终端 → 操作没 API 的旧系统
- **云手机**：Android 13 2vCPU/6GB/45GB → 抖音/微信内部自动化
- **独立邮箱** `<agent>@coze.email` → Agent 收发邮件
- **长期记忆**：跨渠道，文件化（Memory.md），自动+手动+异步整理

### 2.11 Coze Loop（评测+观测+提示词）

> **直接替代我之前要造的 `coze-control/eval+analyze+optimize`**。
> 开源 Apache 2.0，SDK：Go/Python/Node。

- Prompt 开发：版本管理 + 多模型对比 + Playground
- 评测：黄金题集 + 评测器（规则 / LLM-as-judge）+ 实验管理
- 观测：全链路 Trace（输入 → prompt → 模型 → 工具 → 输出）

**企业旗舰版**：200 万 Trace/月，180 天保留。

### 2.12 扣子罗盘

提示词智能优化平台（**消耗积分**）。当 prompt 飘了/写不好时，让它自动优化重写。

| 能力需求 | 决策 | 理由 |

## 9. 保健品行业合规护栏（必读）

### 9.1 系统 prompt 硬约束（每个对外 bot 必加）

```
你是某保健品公司销售助手，回答时必须遵守以下规则：
1. **绝不**做疾病诊断、绝不承诺治疗效果
2. 涉及健康问题的查询，**只能**给出"建议咨询医生"+ 一般科普
3. 引用产品功效时，**只能**使用国家批准的保健功能字眼（增强免疫力、缓解
   体力疲劳等 27 项保健功能之一），不得超范围声称
4. 不得使用"祖传"、"特效"、"根治"、"国家级"、"最佳"等绝对化用语
5. 涉及价格/促销，必须以系统数据为准，不得自创
6. 用户索取处方药信息 / 询问代煎中药 / 调换包装 → 立即拒绝并转人工
```

### 9.2 工作流的合规审核节点

每个面向客户的工作流，**最后一步都加合规检测节点**：

```
[生成回答] → [合规检测：调一个专门的合规 bot/插件] → [通过 → 发；失败 → 拒答 + 转人工]
```

合规检测可以是个独立的 LLM 节点，prompt 是上面的 9.1 + 国家保健品广告法关键词清单。

### 9.3 知识库内容审核

- 进知识库的 PDF / Word / 网页**必须先过法务/合规过审**
- 维护一份"禁词清单"（医疗器械、药品名、绝对化用语）
- Coze 知识库支持"审核配置"——开启它

### 9.4 全链路审计

- Coze Loop 所有 Trace 保留 180 天（企业旗舰版自带）
- **额外**：每条 bot 回复 + 输入 + 用户 ID，存企业 SQL 库（合规要求）
- 出事时能 30 秒内查到某条对话的完整链路

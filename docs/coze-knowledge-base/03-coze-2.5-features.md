# 03 · Coze 2.5 新能力（2026-04-07 发布）

> 2.0（2026-01-19）引入 Agent Skills + Agent Plan。
> **2.5（2026-04-07）引入 Agent World + 云电脑 + 云手机 + 独立邮箱**——这是真正的飞跃。

## 1. Agent World（核心新能力）

> "AI Agent 不再是工具，而是有独立身份和社交关系的**数字员工**"

每个 Agent 拥有：
- 独立身份（可命名、有头像、有简历）
- 长期记忆（跨会话、跨用户）
- 与其他 Agent 的社交关系（互相协作）
- 24×7 自主运行能力

**对企业的意义**：从"按需问答"变成"持续在岗"。
最适合的场景：合规巡检、客户跟进、邮件分诊、长项目跟踪。

## 2. 云电脑（Agent 的"PC"）

| 项 | 规格 |
|---|---|
| 系统 | Ubuntu |
| 配置 | 2 核 / 4 GB |
| 内置 | 浏览器 + 文件系统 + 终端 |
| 支持 | 代码脚本执行、网页浏览、文件处理 |

**关键场景**：
- ✅ 自动化操作没 API 的旧系统（OA / 内部 ERP）
- ✅ 网页爬取 + 数据抓取
- ✅ Excel / Word 批量处理
- ✅ 跑临时脚本（Python / Node）

## 3. 云手机（Agent 的手机）

| 项 | 规格 |
|---|---|
| 系统 | Android 13 |
| 配置 | 2 vCPU / 6 GB / 45 GB |
| 支持 | 装原生 App、页面操作 |

**关键场景**：
- ✅ 抖音 / 微信 / 快手等 App 内自动化
- ✅ 公司有 App 没小程序时的代偿
- ✅ 手机端自动签到、领券、回复

⚠️ **风险**：在微信 / 抖音上做大量自动化操作会触发风控。建议**仅做信息收集 + 内部 App 操作**，不做对外发消息。

## 4. 独立邮箱（@coze.email）

每个 Agent 拿到一个 `<agent_name>@coze.email` 邮箱，可：
- 收邮件 → 触发工作流
- 发邮件 → 给外部客户/合作方/其他 Agent

**关键场景**：
- ✅ 销售助手自动发首封 follow-up
- ✅ 客户回邮件 → Agent 接收 → 进客户档案 + 通知销售
- ✅ Agent 给 Agent 发邮件协作

## 5. Agent Plan（长期计划，2.0 引入）

把模糊目标拆成有序计划，调工具执行，**人工检查节点**做必要确认。

```
用户："把 X 项目跟到 9 月底"
  │
  ▼ Agent Plan 自动拆解：
  1. 每周一拉取项目状态
  2. 偏离 → 通知人 → 等确认
  3. 关键节点 → 出周报
  4. 9 月底 → 项目复盘
```

## 6. Agent Skills（技能，2.0 引入 / 2.5 加全球商店）

把 SOP / 经验 / 工作流封装为**可复用 Skill**：
- 一句话生成（"基于这 5 篇文章生成写作风格"）
- 全球技能商店（Skill Store）
- 上传/下载/付费交易

**对企业的意义**：把销售 SOP、合规检查 SOP、行业 know-how 封装成 Skills 内部共享——这正是 gstack 文档里的"经验引擎"现成版。

## 7. 视频创作 Agent（2.5 增强）

一句话 → 脚本 → 分镜 → 素材 → 视频出片。
适合做内部培训视频、短视频营销素材。

## 8. 哪些 Agent World 能力**不在自部署/HiAgent 上**

| 能力 | SaaS Coze Pro | Coze Studio 自部署 | HiAgent |
|---|---|---|---|
| Agent 独立身份 | ✅ | 部分 | ❌ |
| 云电脑 | ✅ | ❌ | ❌ |
| 云手机 | ✅ | ❌ | ❌ |
| 独立邮箱 | ✅ | ❌ | ❌ |
| 长期记忆 | ✅（1000 万条/库）| 自己实现 | 自己实现 |
| Skill 商店 | ✅ | ❌ | ❌ |

**结论**：要 Agent World 必须用 SaaS Coze Pro。这是 SaaS 唯一不可替代的优势。

# 04 · 企业版深度（你已经买了或要买）

## 1. 谁该用企业版

✅ 用：
- 全公司推广（≥ 10 人）
- 需要 RPM > 5,000
- 知识库 > 100 GB
- 数据合规要求高（VPC / 全链路加密）
- 想用 Agent World（云电脑 / 云手机 / 邮箱）

❌ 不用：
- 个人或 < 5 人小组（个人进阶 9.9 即可）
- 数据极度敏感（医疗/金融核心）→ 用 HiAgent / 自部署 Studio
- 完全可控诉求（自研中台）→ 自部署 Coze Studio + Eino

## 2. 企业版独占特性

### 2.1 安全与合规
- **全链路加密**：传输 + 存储
- **VPC 私有网络**：选项可用
- **按钮级权限**：每个按钮可控制谁能点
- **审计日志**：操作可追溯（**具体保留期搜不到**——见 _gaps.md ②）
- **多级组织管理**：部门 / 子部门 / 跨部门

### 2.2 容量
- 不限工作空间数 / 用户数
- **2 TB 知识库** —— 估算：≈ 1.5 亿字（Word/PDF），中型公司 3-5 年文档
- **1000 万条/库 长期记忆** —— 50 人公司每人每天 50 条，能存 5 年
- **200 万 Trace/月，180 天保留** —— Coze Loop 全链路观测

### 2.3 模型与性能
- **可用方舟（Volcano Ark）模型** —— Doubao 系列、深度思考、视频
- **12,000 RPM** —— 50 人公司高并发够用（每人 240 次/分钟峰值）
- **缓存命中折扣** —— 输入 token 缓存命中部分单价更低

### 2.4 协作
- **跨空间资源迁移** —— bot / KB / workflow 可在工作空间间复制
- **不限语音克隆**
- **降噪 + 语义停顿检测** —— 客服/会议场景重要

### 2.5 价格机制
- 4,980 元/月
- **年付 8.3 折** ≈ 4,134 元/月（一年省 ≈ 10,152 元）
- 资源点不够可单买（具体单价 _gaps.md ③）

## 3. 企业版 ≠ 私有部署

⚠️ **关键区分**：
- **企业版** = 还是在 coze.cn 的 SaaS 上跑，**数据存字节的服务器**（带 VPC 选项可隔离）
- **私有部署** = 用 Coze Studio 开源版自己部署，**数据完全在你公司**，但**没 Agent World**

如果你公司的合规要求是"数据不能出公司"，**仅企业版 + VPC 不够**——需要看 HiAgent 或 Coze Studio 自部署。

## 4. 如何用足企业版

### 4.1 一定要开的硬控
1. **月预算上限** —— 防爆账单（具体在哪开 _gaps.md ④）
2. **审计日志开启** —— 推广必备
3. **VPC 网络** —— 跟内部系统对接更稳

### 4.2 推广必走的 3 步
1. **建组织树** —— 按部门划工作空间
2. **配角色权限** —— owner / admin / member 各部门一份
3. **设资源点配额** —— 部门级配额，防一个部门爆刷

### 4.3 Coze Loop 必接
企业版 200 万/月 Trace 够，**所有生产 bot 必须接 Loop**：
- prompt 版本可回滚
- 评测集每天跑一次
- 慢调用 / 错调用自动告警

## 5. 企业版的"隐性成本"

| 成本项 | 估算 | 说明 |
|---|---|---|
| 月费 | ¥4,980 | 现金 |
| 年付折扣 | -¥10,152/年 | 8.3 折 |
| 私有部署成本（如另选）| ¥30k-100k/年 | K8s/运维/开发 |
| 推广人力 | 0.3-1 FTE | 培训/答疑/迭代 |
| 业务方培训 | 5-10 天 | 让业务方自助 |
| 模型超额（中型公司）| ¥0-2,000/月 | 看用量 |

## 6. 续费决策点（提前 30 天准备）

到期前评估：
1. 实际 DAU 渗透率 ≥ 20% → 续
2. 至少 1 个核心场景产生可计量价值 → 续
3. < 20% → 砍掉部分功能换团队版（178/月）做止损

## 保健品选品特殊点
- **成分**: 必须合法可用（国家保健食品允许用的原料目录）
- **功效**: 必须对应 27 项中的一项（或多项）
- **注册/备案**: 注册制 (蓝帽子) vs 备案制
- **人群**: 中老年 / 孕产 / 儿童 / 运动 / 美容 / 熬夜党
- **场景**: 早/晚/餐前/餐后/特定季节
- **包装**: 瓶装/袋装/一盒多少粒/一次性小包装
- **对比普通食品**: 价格高 2-5x，需要"功效 + 合规"双背书

## 保健品直播合规要点

必须：
- 直播间挂 "保健食品广告审查批准文件号" 悬浮挂件
- 商品资质卡: 蓝帽子 + 生产许可 + 检测报告
- 主播口播: "本品不能代替药物" "保健食品不是药品"

禁止：
- 宣称疗效: 治疗/治愈/根治/预防 XX 病/替代药品
- 绝对化用语: 最佳/第一/国家级/特效
- 谐音黑话: 小糖人/小发动机等暗示疗效
- 对比药品: "比药管用""不用吃药"
- 安全/功效保证: 无副作用/100% 有效

**合规流程**: 开播前脚本过审 (法务) → 直播中合规岗实时听播 → 下播后录播留档 ≥ 90 天。

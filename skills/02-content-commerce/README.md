## 内容生产 SOP (所有内容类 skill 共用)

```
选题 → 脚本 → 拍摄/剪辑 → 封面标题 → 合规过审 → 发布 → 数据监控 → 爆文复盘
```

每个环节都对应一个或多个 skill。

## 保健品合规要点

每篇内容必须通过三道过滤：
1. **机审**: [forbidden-word-scan](../11-compliance/forbidden-word-scan/) 扫极限词/医疗词
2. **蓝帽子校验**: [27-function-validator](../11-compliance/27-function-validator/) 不扩大宣传
3. **平台规则**: [platform-health-rule-monitor](../11-compliance/platform-health-rule-monitor/) 各平台最新规则

保健品达人合作注意：
- 不得用明星代言（2015 年起《广告法》禁止）
- 不得由"具有一定影响力"达人代言（一般理解 100 万粉以上 KOL 受限）
- 达人需走平台官方报备（蒲公英/星图/百应）否则属违规营销

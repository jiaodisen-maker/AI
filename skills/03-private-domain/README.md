## 保健品私域核心场景

- **营养师 1v1 咨询**: 健康问卷 → 饮食/作息分析 → 产品组合推荐 → 定期复诊
- **打卡晒餐单**: 用户每日晒 → 营养师点评 → 建立信任 → 自然带货
- **用户案例分享**: 收集前后对比 → 法务过审 → 公众号/朋友圈/直播复用
- **定期复购提醒**: 按「开瓶日期 + 用法疗程」算补货日

## 合规红线 (贯穿所有内容/SOP skill)

1. 朋友圈/群内宣传属商业广告，受《广告法》调整
2. 保健食品广告必出现「本品不能代替药物」
3. 不得用国家机关/医生/患者形象做推荐证明
4. 分销层级 ≤ 2 级，避免触碰《禁止传销条例》
5. 不得使用明星代言

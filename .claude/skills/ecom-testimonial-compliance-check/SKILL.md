# 用户见证合规

## Step 1: 扫疗效/形象违规
- 疗效: 治好 / 根治 / 见效 / 瘦了 X 斤
- 形象: 医生推荐 / 患者证言 / 机关推荐
- 对比: 不得暗示疗效

## Step 2: 改写
保留「使用感受」, 去掉「疗效断言」。

## Step 3: 授权书要点
- 用户知晓用于商业宣传
- 品牌不保证相同效果
- 用户保留撤回授权权利
